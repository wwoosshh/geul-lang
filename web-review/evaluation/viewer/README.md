# 예행 검토 화면

실제 참가자 0명, 본 실험 미실시. 이 화면은 표시 방식과 기록 장치를 점검하는 개발 도구다. 참가자 배정·채점·모집·연구 동의를 처리하지 않는다. 모든 응답에는 `practice-only`, `participant: null`, `previewAvailableBeforeStart: true`가 들어간다. 시작 전 자료를 볼 수 있으므로 여기서 얻은 시간은 본 실험의 검토 시간으로 사용하지 않는다.

```powershell
cd web-review
npm.cmd run test:corpus
npm.cmd run prepare:pilot
npm.cmd run practice
```

출력된 `http://127.0.0.1:<port>` 주소를 연다. 포트를 고정하려면 `npm.cmd run practice -- --port 56677`처럼 지정한다. 서버는 localhost에만 열리고, 고정 자료와 허용된 원본만 읽어 준다. `private/answer-key.json`과 배정표 경로는 제공하지 않는다. 응답 POST·외부 Origin 요청·목록 밖 파일 요청은 거절한다. 원본 파일의 해시가 바뀌면 원본 열기를 거절한다.

네 과제에서 원본·질문·도메인·용어·파일 접근을 공통으로 제공한다. B에는 글의 실행 비교, C에는 같은 도메인의 결정표, D에는 구조를 유지한 한국어 풀이를 추가한다. 예행 검토이므로 조건을 직접 고를 수 있으며 이를 무작위 배정으로 취급하지 않는다.

시작하면 과제·조건을 고정하고 시간과 원본 줄 이동을 기록한다. AI 대기와 창 비활성 시간은 전체 시간에 포함하며 각각 별도로 남긴다. 두 보조 시간은 겹칠 수 있다. AI 질문 횟수와 도구 이름은 자기 보고다. 원본 이동은 화면 안의 원본 보기·줄 이동 횟수이며 외부 편집기나 GitHub 이동을 자동으로 추적한 수치가 아니다.

답변은 브라우저 메모리에만 있다. 제출 동작은 응답 JSON을 만들고 브라우저 다운로드를 요청한다. 내장 브라우저 검사에서는 다운로드 이벤트가 발생하지 않았으므로 파일 저장 성공을 단정하지 않는다. 마지막 응답 JSON을 화면에서 읽고 전체 선택해 복사하는 대안이 있다. 자동 UI 검사에서 내용·선택 길이를 확인했다. 새로고침하면 저장하지 않은 답변은 사라진다.

자동 검사에서 4개 과제×4개 조건의 표시, 답안 유지, 원본 줄 이동, 응답 생성·전체 선택, 390px·1280px 화면의 가로 넘침, 브라우저 오류 기록을 확인했다. 사람에게 읽기 쉽다는 증거와 구분한다. 본 실험으로 전환하려면 사람 예행 검토, 최종 질문·채점표, 배정 적용, 동의와 중단 처리, 시간 측정 운영 점검이 먼저 필요하다.

내보낸 예행 응답은 [예행 채점 도구](../SCORING.md)에서 현재 자료 해시를 확인한 뒤 조건 메타데이터를 가린 양식으로 변환할 수 있다. 사람이 점수와 근거를 입력하며 도구는 자유 서술의 정답을 자동 판정하지 않는다. 채점 기준은 초안이고 실제 참가자 평가를 시작하는 기능은 아니다.

# 명세 수용 테스트 (D-06 확정 형식)

테스트 하나 = 디렉터리 하나. 디렉터리 이름은 `<명세 절>/<번호>-<이름>`.

```
main.gl          컴파일할 소스. 포함 파일이 있으면 같은 디렉터리
expect.stdout    기대 표준출력 (없으면 빈 출력)
expect.code      기대 종료코드 (없으면 0)
expect.errors    부정 테스트: 컴파일러 오류 메시지에 포함돼야 할 부분 문자열, 한 줄에 하나
stdin.txt        선택: 표준입력
```

규칙:

- `expect.errors`가 있으면 컴파일이 **실패해야** 통과다. 없으면 컴파일 실패는 실패다. 건너뜀은 없다.
- 러너 종료코드: 실패가 하나라도 있으면 1.
- 부정 테스트의 부분 문자열이 곧 오류 메시지 명세다. 메시지를 바꾸면 테스트도 바꾼다.
- 명세의 모든 예제는 여기 있는 어떤 테스트의 `main.gl`과 같아야 한다.

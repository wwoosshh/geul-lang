# 글 (geul) 2세대

한글 키워드와 한국어 어순(SOV)으로 프로그래밍하는 언어 **글**의 두 번째 설계입니다.
목표는 1세대와 같습니다. 과정이 다릅니다.

## 같은 목표

- 100% 한글 키워드. 조사(을/를/에/로…)가 인자의 역할을 정하고, 동사형(`쓰다` → `쓰기`)으로 함수를 부른다.
- C 컴파일러 없이 `.gl` → Windows `.exe`를 직접 만든다 (x86-64 PE 직접 생성).
- 컴파일러가 자기 자신을 컴파일한다 (자체호스팅).

## 다른 과정

1세대 감사(2026-09-03)에서 확인된 결함은 국소 버그가 아니라 네 가지 설계 결정에서 나왔습니다.
상태 의존 토큰화, 타입 없는 IR, 조용한 실패, 너무 이른 자체호스팅.
2세대는 이 넷을 설계 단계에서 뒤집습니다. 규칙은 [docs/00-헌장.md](docs/00-헌장.md)에 있습니다.

## 현재 상태

**3단계(자체호스팅) 진행 중.** 설계 결정 D-01~D-11 확정(2026-09-03), 문법 명세 판 1, 수용 테스트 114개.
`ref/`의 Python 참조 컴파일러가 114개 전부를 통과합니다 (`python build.py test`).
표준 라이브러리 9개 모듈(기본·문자열·입출력·수학·목록·배열·사전·바이트열·시간·체계)이 있고, 글로 쓴 렉서·파서·의미 분석·IR 하강(`self/`)이 참조 구현과 토큰·AST·IR 덤프가 일치합니다 (`python build.py selfhost`). 다음은 코드 생성·PE 출력입니다.

```
python build.py test            # 수용 테스트 전체
python build.py selfhost        # 자체호스팅 단계별 교차 검증
python ref/geulc.py 파일.gl     # 파일.exe 생성
python ref/geulc.py --check 파일.gl
```
요구사항: Python 3.12 (개발자만). 생성된 exe 는 msvcrt.dll·kernel32.dll·shell32.dll 만 쓴다.

## 진행 순서

1. **명세와 코퍼스** — 문법 명세 확정, 1세대 코퍼스를 명세에 맞게 고쳐 수용 테스트로 만든다. 코드 없음.
2. **참조 구현** — 명세를 그대로 구현하는 참조 컴파일러. 수용 테스트 전체 통과가 완료 조건.
3. **자체호스팅** — 언어가 컴파일러를 편하게 쓸 수 있을 만큼 성숙한 뒤. 참조 구현은 영구 부트스트랩으로 남긴다.

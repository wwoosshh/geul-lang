# 백업

원본 디렉터리의 내용을 대상 디렉터리에 맞춘다. 대상에만 있는 것은 지우지 않는다 — 백업이지
거울이 아니다.

```
백업 <원본> <대상> [-n] [-q]

  -n, --보기만    무엇을 할지만 보이고 아무것도 바꾸지 않는다
  -q, --조용히    파일마다의 줄을 찍지 않는다
```

```
> 백업 문서 D:\백업\문서
디렉터리 D:\백업\문서
복사 D:\백업\문서\메모.txt
복사 3개, 건너뜀 12개, 새 디렉터리 1개, 51200바이트
```

이미 있고 크기와 수정 시각이 같은 파일은 건너뛴다. 종료 코드는 0(성공), 1(실패 있음),
2(쓰는 법이 틀림)다.

## 왜 이 도구를 글로 썼는가

**원본과 대상을 바꿔 쓰면 자료가 날아간다.** 다른 언어에서 `sync(a, b)` 는 조용히 컴파일된다.
글에서는 안 된다.

```
파일복사("가.txt", "나.txt").
```
```
오류: '파일복사' 호출에서 두 인자를 바꿔 써도 컴파일됩니다:
      '원본'(에서), '대상'(로) — 둘 중 하나에 역할 조사를 붙여 구별하세요
```

선언이 이렇기 때문이다.

```
[문자열 원본에서 문자열 대상으로 파일복사]는 -> 참거짓
```

같은 타입인 두 매개변수의 **역할이 다르면** 부르는 쪽이 조사를 붙여야 한다 (D-30). 붙이면
차례는 마음대로다 — 조사가 어느 값이 어느 자리로 가는지 말해 주기 때문이다.

```
원본에서 대상으로 파일복사하다.
대상으로 원본에서 파일복사하다.     (* 같은 호출 *)
파일복사(대상 으로, 원본 에서).      (* 이것도 같다 *)
```

문법에 격이 있어야만 할 수 있는 검사다. 다른 언어는 인자에 이름을 붙이는 비용이 커서 위치
호출이 기본이고, 그래서 강제할 수 없다.

## 격이 못 지켜 주는 자리도 있다

`경로잇기(앞, 뒤)` 는 두 인자가 **같은 격**이라 조사로 구별되지 않는다. `--dump-risky` 가
그런 자리를 `주의` 로 알려 준다. 격은 닫힌 작은 어휘이고 이름은 무한하다 (D-32).

## 창 (백업창.gl)

같은 기능을 Win32 창으로 감쌌다.

```
geulc 프로그램/백업창.gl --창 -o 백업창.exe
백업창.exe [원본] [대상]
```

원본·대상 칸과 `찾아보기` 단추, `보기만` 상자, `백업 시작` 단추, 결과 칸이 있다. 명령줄로 준
경로는 칸에 미리 채워진다. `--창` 은 콘솔 없이 뜨게 한다 (D-39).

창이 가능해진 것은 **D-38** 덕이다. 그 전에는 외부 선언이 부를 수 있는 DLL 이
`kernel32`·`shell32`·`msvcrt` 로 고정이라 `user32` 를 부를 방법이 아예 없었다.

```
외부 "user32.dll" "CreateWindowExW" [...]는 -> 공허 참조.
외부 "gdi32.dll" "GetStockObject" [중간정수 무엇을 기성물건]는 -> 공허 참조.
외부 "shell32.dll" "SHBrowseForFolderW" [공허 참조 정보를 폴더고르기]는 -> 공허 참조.
```

**창처리(WndProc)는 Windows 가 글 함수를 되부르는 자리다.** 함수 값을 그대로 넘긴다.

```
묶음 창클래스는 정수 양식, [공허 참조, 정수, 정수, 정수 -> 정수] 창처리, …

wc의 창처리 = 창처리.
```

글의 문자열은 UTF-8 이고 Win32 의 `W` 함수는 UTF-16 이라 `경로_넓게` 와 `UTF8로` 로 오간다.

## 파일

| | |
|---|---|
| `백업기능.gl` | 견주기·복사·재귀 맞추기. `시작하기` 가 없어 다른 프로그램이 `포함` 할 수 있다 |
| `백업.gl` | 명령줄 도구 |
| `백업창.gl` | Win32 창. user32·gdi32·shell32 를 부른다 |

`spec-tests/프로그램-프로젝트/07-백업` 이 임시 디렉터리에서 실제로 돌려 확인하고,
`spec-tests/4-의미/12-원본대상-바꿔쓰기` 가 위의 보호가 살아 있는지 확인한다.

## 만들기

```
python ref/geulc.py 프로그램/백업.gl -o 백업.exe
```

또는 배포된 컴파일러로.

```
geulc 프로그램/백업.gl -o 백업.exe
```

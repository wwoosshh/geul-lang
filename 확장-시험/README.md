# 확장 시험 (명세 9절, D-51)

컴파일러를 품는 프로그램의 두 스위치 — 조각 모드와 연구 옵션 — 를 켠 앞단의 시험이다. 명령줄 컴파일러는 이 스위치로
실행 파일을 만들지 않으므로 `spec-tests/` 처럼 돌리지 않고, `python build.py selfhost 확장` 이 두 구현의 앞단으로 견준다.

테스트 하나 = 디렉터리 하나다(`spec-tests/` 와 같은 꼴).

```
main.gl          소스
opts.txt         켤 스위치, 한 줄에 하나: --조각 (조각 모드), --연구 (연구 옵션)
expect.errors    부정 테스트: 오류 메시지에 들어야 할 부분 문자열, 한 줄에 하나
```

- 참조 구현은 `python ref/geulc.py --dump-ir <opts> main.gl`, 자체 구현은 IR 덤프 드라이버(`self/IR덤프.gl`)에 같은 옵션을 준다.
- 맞는 프로그램은 둘 다 종료 코드 0 이고 IR 덤프가 글자까지 같다.
- 부정 테스트는 둘 다 종료 코드 1 이고, 첫 오류 줄(파일:줄:열: 메시지)이 같고, `expect.errors` 의 조각이 양쪽에 다 있다.

| 시험 | 무엇을 |
|---|---|
| `01-조각-시작하기-없이` | 조각 모드: `시작하기` 없는 소스, 표준 라이브러리가 저절로 들지 않음, IR 덤프의 `진입 없음` |
| `02-반실수-넓히기와-셈` | 밝힌 좁히기(`fptrunc`), 암시 넓히기(`fpext`), 셈 · 비교 · 단항 `-` 는 짧은실수로 |
| `03` ~ `05` | 암시 좁히기는 오류 — 짧은실수 · 실수 리터럴 · 정수에서 |
| `06-연구-옵션-없이` | 연구 옵션을 켜지 않으면 `반실수` 는 타입이 아니다 |

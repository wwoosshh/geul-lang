## D-01 토큰화와 조사 분리 — 확정 (2026-09-03)

**배경.** 1세대는 렉서가 심볼 테이블·파서 모드를 보고 단어 끝의 조사를 잘랐다. 같은 글자열이 선언 순서에 따라 다르게 토큰화되어 합성어 식별자가 깨졌고(R-02), v0.8의 수정은 컨텍스트 하나에 조건을 더한 우회였다.

**선택지.** A 파서 주도 분리 / B 명시적 경계(공백 강제) / C 사전 우선 최장 일치.

**결정.** A. 렉서는 한글 단어를 통째로 `단어` 토큰으로 내보내고, 키워드·접사는 전체 일치일 때만 구분한다. 분리는 파서가 문법 위치에 따라 한다.

- 이름 위치(선언, 타입): 분리하지 않는다.
- 인자 위치: 끝에서 **가장 긴** 접사를 뗀다. 없으면 무표.
- 동사 위치: 어미를 떼고 동사형 규칙으로 함수를 찾는다.
- 이름이 접사로 끝나는 단어를 인자 위치에 쓰려면 괄호로 감싼다: `(데이터와)를 쓰다`.

렉서는 심볼 테이블을 갖지 않는다. 이 규칙의 결정성은 명세 2.2에 그대로 적는다.

## D-02 IR 형태 — 확정 (2026-09-03)

**결정.** 타입 부착 3주소 코드, 비SSA.

- 모든 임시값·변수·상수에 타입: 정수 `i8/i16/i32/i64` × 부호, 실수 `f32/f64`, 포인터(대상 타입 포함), 묶음, 함수 타입.
- 산술·비교 명령은 양쪽 타입이 같아야 한다. 다르면 IR 생성 단계의 내부 오류(의미 분석이 먼저 명시 변환 명령을 삽입해야 한다).
- 변환은 명시적 명령(`sext/zext/trunc/itof/ftoi/fext/ftrunc/bitcast`).
- 즉시값은 타입 폭을 넘으면 의미 분석 오류. 인코더는 범위를 다시 검사하고 넘으면 내부 오류.
- 비교 명령은 부호를 명시한다. 백엔드는 IR 밖의 어떤 플래그도 참조하지 않는다.

**세부 결정.** `정수`는 64비트 유지(1세대 호환). `짧은정수` 16, `작은정수` 8, `문자` 8, `참거짓` 8, `실수` 64, `짧은실수` 32.

## D-03 실패 정책 — 확정 (2026-09-03)

- 진단 범주는 `오류` 하나. 경고는 없다.
- 오류가 하나라도 있으면 출력 파일을 만들지 않는다. 기존 출력 파일이 있으면 삭제한다.
- 내부 한계를 두지 않는다. 자료구조는 늘어나는 배열. 불가피한 한계(예: 인코딩 범위)는 명세에 수치로 적고 초과 시 오류.
- 컴파일러 내부 불변식 위반은 "내부 오류"로 보고하고 종료코드 2. 조용히 진행하지 않는다.
- 종료코드: 0 성공 · 1 사용자 오류 · 2 내부 오류 · 3 사용법 오류.
- 메시지 형식: `파일:줄:열: 오류: 메시지`. 위치는 항상 포함. 한 번의 실행에서 가능한 한 여러 오류를 보고하되, 첫 오류 이후의 오류는 파생 오류를 억제한다.
- 부정 테스트의 `expect.errors` 부분 문자열이 곧 메시지 명세다. 메시지 문구를 바꾸면 테스트를 같이 바꾼다.

## D-04 참조 구현과 부트스트랩 — 확정 (2026-09-03)

**결정.** 참조 구현은 **Python**(3.12+, 표준 라이브러리만, 외부 패키지 없음). 위치 `ref/`.

- 참조 구현은 명세의 실행 가능한 정의다. 성능 목표는 없다.
- 자체호스팅 이후에도 삭제하지 않고 영구 부트스트랩으로 유지한다. 자체호스팅 컴파일러와 참조 구현은 같은 수용 테스트를 통과해야 하고, 같은 소스에 대해 같은 바이트의 exe를 내야 한다(교차 검증). 이것이 고정점보다 강한 검증이다.
- 표준 라이브러리·런타임이 새 외부 심볼을 쓰려면 먼저 참조 구현이 그것을 링크할 수 있어야 한다. "새 컴파일러가 있어야 컴파일러를 빌드"하는 상황은 설계 오류.
- 개발 요구사항: Python 3.12. 사용자 배포 요구사항: 없음(1세대와 동일).

## D-05 문법 정리 — 확정 (2026-09-03)

| 개념 | 결정 |
|---|---|
| 함수 호출 | SOV 문과 직접 호출 둘 다 정식. 의미 차이는 하나: SOV는 조사 역할로 대응, 직접 호출은 표면 순서로 대응 |
| 반환 타입 화살표 | `->` 정식. `→`는 순수 어휘 별칭(멤버 접근 `→`와는 토큰이 다름: 함수 헤더의 `]` 뒤에서만 반환 화살표) |
| 선언 초기화 | `타입 이름 = 식.` 하나. `이름은 식.` 초기화 제거. `은/는`은 함수·묶음·나열·별칭 선언 헤더의 구두점으로만 남는다 |
| 포인터 타입 | `타입 참조` 하나. `타입*` 없음 |
| 주소 취득 | `&식` (세부 결정) |

| 논리 연산 | `그리고`, `또는`, `아닌` 키워드. 단락 평가. `&&`/`\|\|`/`!` 없음. 산술 대체 관용구는 문서에서 삭제 |
| 조건부 컴파일 | 제외 (`만약정의`, `만약미정의`, `끝` 키워드 없음) |
| 가변인자 | 외부 함수 선언의 `...`만. 가변인자 함수 정의·`가변목록` 제외 |
| 정적 | 정적 지역 변수만. `정적 [함수]` 제외 |
| 매크로 | `정의` 제외. 상수는 `상수 정수 최대 = 100.` |
| 증감 | `++`/`--` 제외. `값을 증가하다.`/`값을 감소하다.` 증감문 하나 (코퍼스 변환 중 세부 결정: 1세대 예제 13개가 한글형, 5개가 `++`) |
| 32비트 정수 | `중간정수`(32비트) 추가. C 의 `int` 를 반환하는 외부 함수를 정확히 선언하기 위함 — 1세대는 int 반환값의 상위 32비트를 그대로 써서 오답이 났다 (세부 결정, 표준 라이브러리 작성 중) |
| 멤버 접근 `의` | 식·인자 위치에서 항상 분리. `의`로 끝나는 이름은 선언 불가 (세부 결정) |

| 숫자 리터럴 밑줄 | 허용, 값에 영향 없음 (`1_000` = 1000). 연속 밑줄·끝 밑줄은 오류 |
| 문자 리터럴 | 코드포인트 ≤ 127만 허용, 값은 그 코드포인트. 그 외는 오류 (세부 결정. 한글 글자는 `문자열`로) |
| 주석 | `(* … *)`, 중첩 허용. 미종결 주석·문자열은 오류 |
| 우선순위 | 명세 3.8 표. 후위 > 단항 > 변환 > 곱셈 > 덧셈 > 시프트 > 관계 > 동등 > `&` > `^` > `\|` > 그리고 > 또는 > 삼항 |

## D-07 텍스트·인코딩·런타임 경계 — 확정 (2026-09-03)

- 소스: UTF-8. 선행 BOM 제거. NFC 요구 (정규화하지 않음, 결합형 자모는 오류). 줄 끝 LF/CRLF.
- 명령줄: 시작 코드가 `GetCommandLineW` → `CommandLineToArgvW` → UTF-8 변환. `시작하기`가 받는 argv는 UTF-8.
- 파일 경로: UTF-8 → UTF-16 → 와이드 API.
- 콘솔: 시작 코드가 `GetConsoleOutputCP`로 원래 값을 저장하고 `SetConsoleOutputCP(65001)` 설정, 종료 시 복원. `system()` 호출 삽입 금지. `pause` 없음.
- 종료코드: `시작하기` 반환값. 반환 타입이 없으면 0.

# 표준 라이브러리

명세 7절의 본문이다. 모든 모듈은 C 런타임 없이 kernel32 위에 글로 쓰여 있고, 기능마다 `spec-tests/표준-*` 에 테스트가 있다. 함수 헤더의 조사는 명세 3.5 의 역할이며, 직접 호출(`이름(인자, ...)`)로도 SOV 문으로도 부를 수 있다.

`표준/기본.gl` 은 자동 포함이고, 나머지는 `포함 "표준/이름.gl"` 로 가져온다. 모듈 이름은 접두어 규약(D-15)이다: `문자열_찾기`, `사전_넣기`.

### 서식 지정자

`%[플래그][폭][.정밀도][길이]변환`. 플래그 `-`(왼쪽 정렬) `0`(영 채움) `+`(부호) ` `(양수 앞 공백). 폭과 정밀도는 숫자 또는 `*`(인자에서). 길이 `l`·`ll`·`h` 는 받아들이되 뜻이 없다 — 인자는 언제나 64비트로 넘어온다 (`%d` 와 `%lld` 는 같다).

| 변환 | 뜻 |
|---|---|
| `d` `i` | 부호 있는 정수 |
| `u` | 부호 없는 정수 (`ll` 이 없으면 32비트로 자른다) |
| `x` `X` | 16진 (`ll` 이 없으면 32비트로 자른다) |
| `c` | 바이트 하나 |
| `s` | 문자열 (정밀도는 바이트 수 제한, `없음` 은 `(null)`) |
| `f` | 고정 소수점. 이진 값의 정확한 십진 전개를 정밀도(기본 6) 자리에서 절반 올림 |
| `e` `E` | 과학 표기 `d.dddddde+XX` (정밀도 기본 6, 지수는 두 자리 이상) |
| `g` `G` | 유효 자릿수 P(기본 6, 0 은 1)로 반올림해 지수가 -4 미만이거나 P 이상이면 `e` 꼴, 아니면 `f` 꼴. 끝의 0 과 `.` 은 뗀다 |
| `p` | 16진 대문자 |
| `%%` | `%` |

무한과 NaN 은 `inf`·`-inf`·`nan` 이다. 실수 인자는 배정밀도 비트로 넘어오므로 `%f` 에 정수를 주면 쓰레기가 나온다 — 타입은 호출자가 맞춘다.

## 서식 (`표준/서식.gl`, 기본이 포함)

큰수 산술(`큰수_*`)과 `실수_서식`·`실수_지수서식`·`실수_일반서식`·`실수_유효자릿수`·`정수_서식`. 직접 쓸 일은 드물다.

|---|---|
| `파일_열기(경로, 모드)` `파일_닫기` `파일_삭제(경로)` | 열기 실패는 `없음` |
| `줄_읽기(버퍼, 길이, 파일)` `파일_글자읽기` `파일_읽기(버퍼, 단위, 개수, 파일)` | C 의 fgets/fgetc/fread 와 같다 (끝은 `없음`/-1) |
| `파일_글넣기(문장, 파일)` `파일_글자넣기(바이트, 파일)` `파일_쓰기(버퍼, 단위, 개수, 파일)` `파일에_쓰기(파일, 형식, ...)` | 쓰기 |
| `파일_위치이동(파일, 위치, 기준)` `파일_위치` `파일_끝인가` `출력_비우기` | 기준 0 처음, 1 현재, 2 끝 |
| `표준입력()` `표준출력()` `표준오류()` | 파일로 쓸 수 있는 표준 스트림. 콘솔 입력은 UTF-16 으로 읽어 UTF-8 로 준다 |

## 수학 (`표준/수학.gl`)

`원주율` `자연상수` `자연로그2`. `제곱근` `거듭제곱(밑, 지수)` `내림` `올림` `자르기` `반올림` `실수_나머지(왼, 오른)` `실수_절댓값` `사인` `코사인` `탄젠트` `자연로그` `상용로그` `지수함수` `실수_최솟값` `실수_최댓값` `정수_거듭제곱(밑, 지수)`, 그리고 `실수_무한인가` `실수_NaN인가` `실수_무한()` `실수_NaN()`. 제곱근·내림·올림·나머지·절댓값과 정수 지수의 거듭제곱은 정확하고, 초월 함수는 배정밀도 안에서 근사한다.

## 정렬 (`표준/정렬.gl`)

`정렬(자료, 개수, 원소크기, 비교)` — 제자리 힙 정렬. `비교`는 `[공허 참조, 공허 참조 -> 정수]` 함수로, 음수면 앞 원소가 먼저다. 안정 정렬은 아니다. `정수목록_정렬(목록)` `문자열목록_정렬(목록)`(바이트 순), 비교 함수 `정렬_정수비교` `정렬_문자열비교`.

## 디렉터리 (`표준/디렉터리.gl`)

`경로_있는가(경로)` `디렉터리인가(경로)` `디렉터리_만들기(경로)`(이미 있어도 참) `현재_디렉터리()`(새 문자열) `파일_크기(경로)`(없으면 -1) `디렉터리_목록(경로)`(`.`·`..` 제외, 바이트 순 정렬한 `문자열목록`, 없으면 `없음`).

## 일반목록.gl — `목록(T)` (제네릭, D-19)

`포함 "표준/일반목록.gl"`. 어떤 타입이든 담는 늘어나는 배열. `정수목록`·`문자열목록`의 일반형이며 원소는 값으로 복사된다 (묶음도 가능).

| 함수 | 뜻 |
|---|---|
| `목록_만들기(T)()` → `목록(T) 참조` | 빈 목록 (T 는 명시해야 한다 — 매개변수에 없다) |
| `목록_추가(l, 값)` / `값을 l에 목록_추가하다` | 뒤에 붙인다 (T 추론) |
| `목록_값(l, 위치)` → `T` | 위치의 값. 범위를 벗어나면 조각과 같은 범위 오류 (종료 1) |
| `목록_설정(l, 위치, 값)` | 위치의 값을 바꾼다 |
| `목록_길이(l)` → 정수 | 길이 |
| `목록_조각(l)` → `T[]` | 자료를 길이만큼 조각으로 (목록이 늘어나면 무효) |
| `목록_해제(l)` | 자료와 목록을 해제 |

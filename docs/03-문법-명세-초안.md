# 글 2세대 문법 명세

판: 2026-09-03 (D-01~D-11 확정 반영). 아직 "초안"인 이유는 표준 라이브러리(7절)와 일부 메시지 문구가 테스트로 고정되지 않았기 때문이다.
이 문서의 예제는 전부 `spec-tests/`의 테스트여야 한다. 테스트가 없는 예제는 실을 수 없다.

## 0. 표기법

EBNF. `"…"` 리터럴, `[ ]` 선택, `{ }` 반복, `|` 대안.

## 1. 소스 텍스트

- 인코딩 UTF-8. 선행 BOM은 무시한다. 읽은 뒤 NFC로 정규화한다.
- 줄 끝은 LF 또는 CRLF. 위치는 1부터 세는 줄·열(열은 코드포인트 단위).
- 확장자 `.gl`.

## 2. 어휘 구조

### 2.1 토큰

렉서는 심볼 테이블을 갖지 않는다.

```
토큰 = 키워드 | 접사 | 단어 | 식별자 | 정수리터럴 | 실수리터럴 | 문자리터럴 | 문자열리터럴 | 기호 | 종결
```

- `키워드`: 2.3 목록과 전체 일치하는 한글 단어.
- `접사`: 2.4 목록과 전체 일치하는 단독 한글 단어.
- `단어`: 그 밖의 한글(음절·자모) 연속. 라틴 문자·숫자가 섞여도 한글로 시작하면 단어다(`블록Y`). 뒤에 붙은 접사가 있어도 렉서는 자르지 않는다.
- `식별자`: 라틴 문자 또는 밑줄로 시작하는 라틴·숫자·밑줄 이름 (`argv`, `x1`).
- `종결`: `.` 뒤에 공백·줄바꿈·EOF·`}`·`)`가 오는 경우. 숫자 사이의 `.`은 실수 리터럴의 일부.
- `기호`: `( ) [ ] { } , : -> → & + - * / % < > <= >= == != << >> ^ | ~ ? = += -= *= /= %= &= |= ^= <<= >>= ++ --`.

### 2.2 단어의 분리

`단어`의 해석은 파서가 문법 위치로 정한다.

- **이름 위치** (변수·필드·매개변수·함수 이름 선언, 타입 이름, 나열 값): 단어 전체가 이름. 분리하지 않는다.
- **인자 위치** (SOV 문의 인자, 조건 `X이/가 Y보다` 의 X와 Y): 단어 끝에서 2.4의 접사 중 **가장 긴 것**을 뗀다. 남은 부분이 이름. 뗄 접사가 없으면 단어 전체가 이름이고 역할은 무표.
- **동사 위치** (SOV 문의 마지막 단어): 끝에서 어미(`다`, `고`, `서`)를 떼고 남은 어근을 2.6 규칙으로 함수에 대응시킨다.
- **식 위치** (연산자 사이, 괄호 안, 색인 안, 대입 좌변): 분리하지 않는다. 단어 전체가 이름.
- 이름이 접사로 끝나는 단어를 인자 위치에 쓰려면 괄호로 감싼다: `(데이터와)를 쓰다`.

결정성: 위치는 문법이 정하고, 접사 목록은 고정이며, 선언 순서는 관여하지 않는다. 같은 소스는 언제나 같은 토큰열과 같은 분리 결과를 낸다.

### 2.3 키워드

```
정수 긴정수 짧은정수 작은정수 부호없는 실수 짧은실수 문자 문자열 참거짓 공허   (타입)
참조                                                                   (포인터)
참 거짓 없음                                                            (리터럴)
포함 외부 정적 상수 별칭 묶음 나열 합침                                   (선언)
반환 이면 아니면 동안 반복 반복하기 갈래 경우 기본 탈출 계속               (제어)
그리고 또는 아닌                                                        (논리)
크기                                                                   (sizeof)
시작하기                                                               (진입점, 예약)
```

없는 것: `정의`, `만약정의`, `만약미정의`, `끝`, `가변목록`, `가변시작`, `가변끝`, `정리`, `넘기다`.

### 2.4 접사

조사(역할 표지). 인자 위치에서 뗀다.

| 조사 | 역할 |
|---|---|
| 을, 를 | 대상 |
| 에 | 목적지 |
| 에서 | 출처 |
| 로, 으로 | 수단 |
| 와, 과 | 동반 |
| 보다 | 비교 기준 (조건에서만) |
| 이, 가 | 주어 (조건에서만) |
| 은, 는 | 선언 헤더의 구두점 (2세대에서는 역할이 아니다) |

멤버 접근의 `의`는 접사가 아니라 후위 연산자(3.8)다.
어미: `다` 서술, `고`·`서` 순차. `면`은 `이면` 키워드로만 쓴다.

### 2.5 리터럴

```
정수리터럴  = 십진 | "0x" 십육진
십진        = 숫자 { 숫자 | "_" 숫자 }        (밑줄은 값에 영향 없음. 연속·끝 밑줄 오류)
실수리터럴  = 숫자 { 숫자 } "." 숫자 { 숫자 } [ ("e" | "E") ["-"] 숫자 { 숫자 } ]
문자리터럴  = "'" 글자 "'"                    (코드포인트 ≤ 127. 그 외는 오류)
문자열리터럴 = '"' { 글자 | 이스케이프 | 보간 } '"'
이스케이프  = "\n" | "\t" | "\r" | "\0" | "\\" | '\"' | "\{" | "\}"
보간        = "{" 이름 "}"
```

정수 리터럴의 타입은 문맥이 정하고, 문맥이 없으면 `정수`. 대상 타입의 폭을 넘는 값은 오류.

### 2.6 동사형 대응

동사 위치의 어근 `X`에 대해 순서대로 찾고 첫 일치를 쓴다. 없으면 오류.

1. `X기` (쓰다 → 쓰기)
2. `X` (계산하기하다 → 계산하기)
3. `X`가 `Y하`이면 `Y` (출력하다 → 출력)

라틴 문자 이름도 같다 (`f하다` → `f`).

### 2.7 주석

`(* … *)`. 중첩 허용. 미종결 주석은 오류. 단항 `*`가 없으므로 `(*`는 항상 주석 시작이다.

## 3. 문법

### 3.1 프로그램

```
프로그램 = { 포함 | 선언 }
포함     = "포함" 문자열리터럴
```

`포함`은 모듈 가져오기다. 같은 파일은 한 번만 처리. 탐색 경로: (1) 현재 파일의 디렉터리 (2) 표준 라이브러리 디렉터리. 컴파일러 실행 파일 위치는 탐색하지 않는다.

### 3.2 선언

```
선언     = 변수선언 | 함수정의 | 외부선언 | 묶음선언 | 나열선언 | 별칭선언 | 합침선언
변수선언 = [ "정적" ] [ "상수" ] 타입 이름 [ "=" 식 ] 종결
함수정의 = "[" { 매개변수 } 이름 "]" 주제조사 [ "->" 타입 ] 블록
매개변수 = 타입 단어                                         (단어 끝 조사가 역할. 이름 위치이지만 역할을 위해 끝 조사 하나를 뗀다)
외부선언 = "외부" [ 문자열리터럴 ] "[" { 매개변수 } [ "..." ] 이름 "]" 주제조사 [ "->" 타입 ] 종결
묶음선언 = "묶음" 이름 주제조사 필드 { "," 필드 } 종결
필드     = 타입 이름
나열선언 = "나열" 이름 주제조사 "{" 이름 { "," 이름 } "}"
별칭선언 = "별칭" 이름 주제조사 타입 종결
합침선언 = "합침" 이름 주제조사 필드 { "," 필드 } 종결
주제조사 = "은" | "는"
```

- 외부선언의 문자열리터럴은 링크 이름이다. 생략하면 함수 이름이 링크 이름.
- `정적`은 함수 안의 변수선언에만 허용. 정적 함수는 없다.
- 이름은 선언 전에 쓸 수 없다. 함수는 프로그램 전체에서 보인다. 같은 스코프의 중복 선언은 오류.
- 매개변수의 이름은 조사를 뗀 나머지다. 같은 역할의 매개변수가 여럿이면 선언 순서가 그 역할 안의 순서다.

### 3.3 타입

```
타입     = 기본타입 | 이름 | 타입 "참조" | 타입 "[" 정수리터럴 "]" | 함수타입
기본타입 = [ "부호없는" ] ( "정수" | "긴정수" | "짧은정수" | "작은정수" ) | "실수" | "짧은실수" | "문자" | "문자열" | "참거짓" | "공허"
함수타입 = "[" [ 타입 { "," 타입 } ] "->" 타입 "]"
```

| 타입 | 폭(비트) | 비고 |
|---|---|---|
| 작은정수 | 8 | |
| 짧은정수 | 16 | |
| 정수 | 64 | 1세대 호환 |
| 긴정수 | 64 | `정수`와 같은 타입 |
| 문자 | 8 | |
| 참거짓 | 8 | 0 / 1 |
| 짧은실수 | 32 | |
| 실수 | 64 | |
| 문자열 | 64 | `문자 참조`의 별칭 |
| 참조 | 64 | |

변환: 폭·부호·종류가 같을 때만 암시적. 산술에서 정수→실수 암시 승격 허용. 그 외는 `식으로 타입` 명시 변환. 문자열↔정수 암시 변환 없음.

### 3.4 문장

```
문장 = 변수선언 | 대입 | SOV문 | 호출문 | 조건문 | 반복문 | 갈래문 | 반환문 | "탈출" 종결 | "계속" 종결 | 블록
블록 = "{" { 문장 } "}"
대입 = 좌변 대입연산자 식 종결 | 좌변 ( "++" | "--" ) 종결
좌변 = 이름 | 좌변 "[" 식 "]" | 좌변 "의" 이름 | 좌변 "→" 이름
```

블록의 문장 수와 중첩 깊이에 한계는 없다.

### 3.5 SOV 문과 호출

```
SOV문  = { 인자 } 동사 종결
인자   = 단어(인자 위치) | 리터럴 조사 | "(" 식 ")" 조사
동사   = 단어(동사 위치)
호출문 = 호출식 종결
호출식 = 이름 "(" [ 식 { "," 식 } ] ")"
```

**역할 정규화.** 인자는 자기 조사의 역할로 같은 역할의 매개변수에 대응된다. 순서와 무관하다. 같은 역할이 여럿이면 표면 순서대로. 남거나 모자라면 오류. 무표 인자는 남은 매개변수에 표면 순서로. 인자는 표면 순서로 평가된다.

직접 호출은 표면 순서로 매개변수 순서에 대응. 두 형식의 의미 차이는 이것뿐이다.

`1을 반환하다`, `(a + b)를 쓰다`처럼 리터럴·괄호식에 조사가 붙는 형식은 정식이다.

SOV 문의 값이 필요하면 식 위치에서 괄호로 감싼다: `정수 결과 = (5를 3에 더하다).`

### 3.6 조건문·반복문·갈래문

```
조건문 = 조건 "이면" 블록 { "아니면" 조건 "이면" 블록 } [ "아니면" 블록 ]
조건   = 식 | 단어 "보다" 단어 비교동사             (X이/가 Y보다 크면: X, Y는 인자 위치)
비교동사 = "크" | "작" | "같" | "다르" | "크거나같" | "작거나같"   (뒤에 "으면"/"면"이 붙어 이면 역할)
반복문 = "(" 식 ")" "동안" 블록
       | "반복" "(" [ 변수선언 | 대입 ] ":" 식 ":" 대입 ")" 블록
       | "반복하기" 블록 식 "동안" 종결
갈래문 = "갈래" "(" 식 ")" "{" { "경우" 식 ":" 블록 } [ "기본" ":" 블록 ] "}"
```

`계속`은 가장 안쪽 반복문으로 간다. 갈래문은 대상이 아니다. `탈출`은 가장 안쪽 반복문 또는 갈래문.

### 3.7 반환

```
반환문 = "반환" [ 식 ] 종결 | 인자 "반환하다" 종결
```

반환 타입이 있는 함수의 모든 경로는 값을 반환해야 한다. 아니면 오류. `시작하기`의 반환값이 종료코드다.

### 3.8 식과 우선순위

```
식 = 삼항
삼항 = 또는식 [ "?" 식 ":" 식 ]
또는식 = 그리고식 { "또는" 그리고식 }
그리고식 = 비트합 { "그리고" 비트합 }
… (표의 순서대로)
단항 = ( "-" | "아닌" | "~" | "&" ) 단항 | "크기" "(" 타입 ")" | 변환
변환 = 후위 [ "으로" 타입 | "로" 타입 ]
후위 = 기본 { "[" 식 "]" | "의" 이름 | "→" 이름 | "(" [ 식 { "," 식 } ] ")" }
기본 = 이름 | 리터럴 | "(" 식 ")" | "(" SOV문본문 ")"
```

| 순위 | 연산자 | 결합 |
|---|---|---|
| 1 | 후위 `[]` `의` `→` 호출 | 좌 |
| 2 | 단항 `-` `아닌` `~` `&` `크기()` | 우 |
| 3 | 변환 `으로/로 타입` | 좌 |
| 4 | `*` `/` `%` | 좌 |
| 5 | `+` `-` | 좌 |
| 6 | `<<` `>>` | 좌 |
| 7 | `<` `>` `<=` `>=` | 좌 |
| 8 | `==` `!=` | 좌 |
| 9 | `&` | 좌 |
| 10 | `^` | 좌 |
| 11 | `\|` | 좌 |
| 12 | `그리고` | 좌, 단락 |
| 13 | `또는` | 좌, 단락 |
| 14 | `? :` | 우 |

- `-a[0]`은 `-(a[0])`.
- 단항 `*`는 없다. 포인터 역참조는 색인 `p[0]`. 묶음 포인터의 멤버는 `p→필드`.
- `&`는 좌변이 될 수 있는 식의 주소.
- 비교와 논리 연산의 결과 타입은 `참거짓`.

### 3.9 문자열 보간

`"{이름}"`은 이름의 타입에 따른 서식으로 치환된다 (정수 `%lld`, 부호없는 `%llu`, 실수 `%f`, 문자열 `%s`, 문자 `%c`, 참거짓 `%d`). 보간이 있는 문자열 리터럴은 `쓰기`(및 `외부` 선언에서 서식 첫 인자를 갖는 함수)의 첫 인자에서만 허용되고, 추가 서식 인자와 섞을 수 없다(오류). 리터럴 중괄호는 `\{`, `\}`.

## 4. 의미 규칙

- 이름 해석: 선언 전 사용은 오류. 섀도잉은 안쪽 블록에서만.
- 타입 검사: 초기화·대입·인자·반환의 타입은 3.3 규칙. 불일치는 오류. 인자 개수·역할 불일치는 오류.
- 배열 경계: 검사하지 않는다.
- 초기화되지 않은 지역 변수 읽기: 정의되지 않은 동작.
- 정수 오버플로: 2의 보수 순환. 0으로 나누기: 정의되지 않은 동작.
- 정적 지역 변수: 프로그램 시작 시 한 번 초기화, 호출 간 유지.

## 5. 프로그램 시작과 종료

- 진입점은 `[시작하기]` 또는 `[정수 argc를 문자열 참조 argv를 시작하기]`. 정확히 하나.
- argv는 UTF-8. 시작 코드가 콘솔 출력 코드페이지를 UTF-8로 설정하고 종료 시 복원한다.
- 컴파일러는 사용자 프로그램에 사용자가 쓰지 않은 호출을 삽입하지 않는다.

## 6. 컴파일러 명령줄

```
geulc <소스.gl> [-o <출력.exe>] [--check] [--dump-ir] [--version] [--help]
```

한글 옵션 없음. 처리되지 않는 옵션은 사용법 오류(종료코드 3). 도움말에 있는 옵션은 전부 동작한다. 종료코드는 D-03.

## 7. 표준 라이브러리 [미완]

자동 포함 `표준/기본.gl` 하나와 주제별 모듈. 매크로 별칭 없음. 최소 집합:

```
외부 "printf" [문자열 형식을 ... 쓰기]는 -> 정수.
외부 "malloc" [정수 바이트를 할당]는 -> 공허 참조.
외부 "free"   [공허 참조 메모리를 해제]는.
외부 "strlen" [문자열 문장을 글자수]는 -> 정수.
```

나머지 함수 목록은 모듈 파일이 정의하며 함수마다 테스트가 붙는다.

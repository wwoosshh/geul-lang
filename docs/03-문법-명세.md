# 글 2세대 문법 명세

판: 2026-09-03 (D-01~D-15 반영). 이 문서는 확정판이다. 실행 가능한 형태는 `ref/`(참조 구현)이고, `spec-tests/`가 문장마다의 시험이다. 표준 라이브러리는 `06-표준-라이브러리.md`. 바꾸려면 결정 기록(02)에 먼저 올린다.
이 문서의 예제는 전부 `spec-tests/`의 테스트여야 한다. 테스트가 없는 예제는 실을 수 없다.

## 0. 표기법

EBNF. `"…"` 리터럴, `[ ]` 선택, `{ }` 반복, `|` 대안.

## 1. 소스 텍스트

- 인코딩 UTF-8. 선행 BOM은 무시한다. 한글은 NFC 여야 하며 컴파일러는 정규화하지 않는다 (결합형 자모는 오류, 2.1절).
- 줄 끝은 LF 또는 CRLF. 위치는 1부터 세는 줄·열(열은 코드포인트 단위).
- 확장자 `.gl`.

## 2. 어휘 구조

### 2.1 토큰

- 소스는 UTF-8 이며 한글은 NFC(완성형 음절)로 쓴다. 결합형 자모(U+1100–U+11FF, U+A960–U+A97F, U+D7B0–U+D7FF)가 나오면 "한글이 NFC 로 정규화되어 있지 않습니다" 오류다 — 컴파일러는 정규화하지 않는다 (같은 글자가 두 가지 바이트열로 존재하면 이름 비교가 깨지므로, 조용히 받지 않는다). 호환 자모(U+3130–U+318F)는 이름 글자로 허용한다.

렉서는 심볼 테이블을 갖지 않는다.

```
토큰 = 키워드 | 접사 | 단어 | 식별자 | 정수리터럴 | 실수리터럴 | 문자리터럴 | 문자열리터럴 | 기호 | 종결
```

- `키워드`: 2.3 목록과 전체 일치하는 한글 단어.
- `접사`: 2.4 목록과 전체 일치하는 단독 한글 단어.
- `단어`: 그 밖의 한글(음절·자모) 연속. 라틴 문자·숫자가 섞여도 한글로 시작하면 단어다(`블록Y`). 뒤에 붙은 접사가 있어도 렉서는 자르지 않는다.
- `식별자`: 라틴 문자 또는 밑줄로 시작하는 라틴·숫자·밑줄 이름 (`argv`, `x1`).
- `종결`: `.` 뒤에 공백·줄바꿈·EOF·`}`·`)`가 오는 경우. 숫자 사이의 `.`은 실수 리터럴의 일부.
- `기호`: `( ) [ ] { } , : -> → & + - * / % < > <= >= == != << >> ^ | ~ ? = += -= *= /= %= &= |= ^= <<= >>= ++ --`.

### 2.2 단어의 분리

`단어`의 해석은 파서가 문법 위치로 정한다.

- **이름 위치** (변수·필드·매개변수·함수 이름 선언, 타입 이름, 나열 값): 단어 전체가 이름. 분리하지 않는다.
- **인자 위치** (SOV 문의 인자, 조건 `X이/가 Y보다` 의 X와 Y): 단어 끝에서 2.4의 접사 중 **가장 긴 것**을 뗀다. 남은 부분이 이름. 뗄 접사가 없으면 단어 전체가 이름이고 역할은 무표. 단, `(` 또는 `[`가 공백 없이 바로 붙은 단어는 호출·색인의 이름이므로 분리하지 않는다 (`파일_끝인가(f)를 쓰다`). 띄어 쓴 `(`는 새 인자의 시작이다 (`n을 (목록에서 1을 값하다)를 쓰다`). 호출과 색인의 여는 괄호는 항상 이름에 붙여 쓴다 (3.8).
- **동사 위치** (SOV 문의 마지막 단어): 끝에서 어미(`다`, `고`, `서`)를 떼고 남은 어근을 2.6 규칙으로 함수에 대응시킨다.
- **식 위치** (연산자 사이, 괄호 안, 색인 안, 대입 좌변): 분리하지 않는다. 단어 전체가 이름. 예외는 아래 `의`뿐이다.
- **`의`**: 식 위치·인자 위치에서 `의`로 끝나는 단어는 항상 `의`를 뗀다(멤버 접근 `위치의 가로`). 따라서 `의`로 끝나는 이름은 선언할 수 없다(오류).
- **조건의 끝**: 조건식의 마지막 단어가 `이면`으로 끝나면 `이면`을 뗀다(`맞음이면`). `동안`도 같다. 숫자·`)`·`]` 뒤의 `이면`은 이미 별개 토큰이다.
- 이름이 접사로 끝나는 단어를 인자 위치에서 무표로 쓰려면 괄호로 감싼다: `(데이터와)를 쓰다`.

결정성: 위치는 문법이 정하고, 접사 목록은 고정이며, 선언 순서는 관여하지 않는다. 같은 소스는 언제나 같은 토큰열과 같은 분리 결과를 낸다.

### 2.3 키워드

```
정수 긴정수 중간정수 짧은정수 작은정수 부호없는 실수 짧은실수 문자 문자열 참거짓 공허   (타입)
증가하다 감소하다                                                        (예약 동사)
참조                                                                   (포인터)
참 거짓 없음                                                            (리터럴)
포함 외부 정적 상수 별칭 묶음 나열 합침                                   (선언)
결과 시도 혹은                                                          (결과, D-18)
반환 이면 아니면 동안 반복 반복하기 갈래 경우 기본 탈출 계속               (제어)
그리고 또는 아닌                                                        (논리)
크기                                                                   (sizeof)
시작하기                                                               (진입점, 예약)
```

없는 것: `정의`, `만약정의`, `만약미정의`, `끝`, `가변목록`, `가변시작`, `가변끝`, `정리`, `넘기다`.

### 2.4 접사

조사(역할 표지). 인자 위치에서 뗀다.

| 조사 | 역할 |
|---|---|
| 을, 를 | 대상 |
| 에 | 목적지 |
| 에서 | 출처 |
| 로, 으로 | 수단 |
| 와, 과 | 동반 |
| 보다 | 비교 기준 (조건에서만) |
| 이, 가 | 주어 (조건에서만) |
| 은, 는 | 선언 헤더의 구두점 (2세대에서는 역할이 아니다) |
| 의 | 멤버 접근 (분리 대상이지만 역할이 아니라 후위 연산자, 3.8) |

어미: `다` 서술, `고`·`서` 순차(3.5의 연결). `면`은 `이면` 키워드와 비교동사 어미(`작거나같으면`)로만 쓴다.

예약 동사: `증가하다`, `감소하다` (3.4의 증감문). 같은 이름의 함수는 정의할 수 없다.

### 2.5 리터럴

```
정수리터럴  = 십진 | "0x" 십육진
십진        = 숫자 { 숫자 | "_" 숫자 }        (밑줄은 값에 영향 없음. 연속·끝 밑줄 오류)
실수리터럴  = 숫자 { 숫자 } ( "." 숫자 { 숫자 } [ 지수 ] | 지수 )     (1.5, 1.5e-3, 1e22, 2E+5)
지수        = ("e" | "E") ["+" | "-"] 숫자 { 숫자 }
문자리터럴  = "'" 글자 "'"                    (코드포인트 ≤ 127. 그 외는 오류)
문자열리터럴 = '"' { 글자 | 이스케이프 | 보간 } '"'
이스케이프  = "\n" | "\t" | "\r" | "\0" | "\\" | '\"' | "\{" | "\}"
보간        = "{" 이름 "}"
```

정수 리터럴의 타입은 문맥이 정하고, 문맥이 없으면 `정수`. 대상 타입의 폭을 넘는 값은 오류.

### 2.6 동사형 대응

동사 위치의 어근 `X`에 대해 순서대로 찾고 첫 일치를 쓴다. 없으면 오류.

1. `X기` (쓰다 → 쓰기)
2. `X` (계산하기하다 → 계산하기)
3. `X`가 `Y하`이면 `Y` (출력하다 → 출력)

라틴 문자 이름도 같다 (`f하다` → `f`).

### 2.7 주석

`(* … *)`. 중첩 허용. 미종결 주석은 오류. 단항 `*`가 없으므로 `(*`는 항상 주석 시작이다.

## 3. 문법

### 3.1 프로그램

```
프로그램 = { 포함 | 선언 }
포함     = "포함" 문자열리터럴
```

`포함`은 텍스트 포함이다 (D-15). 이름공간은 없고 모든 선언은 하나의 전역 이름공간에 있으므로, 모듈은 `모듈_이름` 접두어로 구분한다. 같은 파일은 한 번만 처리. 탐색 경로: (1) 현재 파일의 디렉터리 (2) 표준 라이브러리 디렉터리의 상위(`표준/...` 경로로 쓴다). 컴파일러 실행 파일 위치는 탐색하지 않는다. 포함된 파일은 포함한 파일보다 먼저 처리되므로 그 파일이 선언한 타입 이름을 뒤에서 쓸 수 있다.

### 3.2 선언

```
선언     = 변수선언 | 함수정의 | 외부선언 | 묶음선언 | 나열선언 | 별칭선언 | 합침선언
변수선언 = [ "정적" ] [ "상수" ] 타입 이름 [ "=" 식 ] 종결
함수정의 = "[" { 매개변수 } 이름 "]" 주제조사 [ "->" 타입 ] 블록
매개변수 = 타입 단어                                         (단어 끝 조사가 역할. 이름 위치이지만 역할을 위해 끝 조사 하나를 뗀다)
외부선언 = "외부" [ 문자열리터럴 ] "[" { 매개변수 } [ "..." ] 이름 "]" 주제조사 [ "->" 타입 ] 종결
묶음선언 = "묶음" 이름 주제조사 필드 { "," 필드 } 종결
필드     = 타입 이름
나열선언 = "나열" 이름 주제조사 "{" 이름 { "," 이름 } "}"
별칭선언 = "별칭" 이름 주제조사 타입 종결
합침선언 = "합침" 이름 주제조사 필드 { "," 필드 } 종결
주제조사 = "은" | "는"
```

- 외부선언의 문자열리터럴은 링크 이름이다. 생략하면 함수 이름이 링크 이름.
- `정적`은 함수 안의 변수선언에만 허용. 정적 함수는 없다.
- 이름은 선언 전에 쓸 수 없다. 함수는 프로그램 전체에서 보인다. 같은 스코프의 중복 선언은 오류.
- 매개변수의 이름은 조사를 뗀 나머지다. 같은 역할의 매개변수가 여럿이면 선언 순서가 그 역할 안의 순서다.

### 3.3 타입

```
타입     = 기본타입 | 이름 | 타입 "참조" | 타입 "[" 정수리터럴 "]" | 함수타입
기본타입 = [ "부호없는" ] ( "정수" | "긴정수" | "중간정수" | "짧은정수" | "작은정수" ) | "실수" | "짧은실수" | "문자" | "문자열" | "참거짓" | "공허"
함수타입 = "[" [ 타입 { "," 타입 } ] "->" 타입 "]"
```

| 타입 | 폭(비트) | 비고 |
|---|---|---|
| 작은정수 | 8 | |
| 짧은정수 | 16 | |
| 중간정수 | 32 | C 의 `int`/`long` 과 맞추는 외부 함수 선언용 |
| 정수 | 64 | 1세대 호환 |
| 긴정수 | 64 | `정수`와 같은 타입 |
| 문자 | 8 | |
| 참거짓 | 8 | 0 / 1 |
| 짧은실수 | 32 | |
| 실수 | 64 | |
| 문자열 | 64 | `문자 참조`의 별칭 |
| 참조 | 64 | |

변환 규칙:

- 정수끼리는 암시 변환. 넓히기는 원본이 부호있으면 부호 확장, 없으면 영 확장. 좁히기는 절단. 단, 리터럴이 대상 타입의 범위를 넘으면 오류(`부호없는 작은정수 t = 300.`).
- 정수→실수는 산술 승격에서만 암시. 실수→정수는 `식으로 정수` 명시.
- `공허 참조`는 모든 참조 타입과 양방향 암시 변환. 그 외 참조끼리, 참조↔정수는 명시.
- 문자열↔정수 암시 변환 없음.
- 가변 인자(`...`)로 넘기는 값은 정수는 64비트로, 실수는 `실수`로 승격.
- 함수 이름은 그 함수 타입의 값이다(`함수 = 제곱하기.`). 배열 타입 매개변수는 첫 원소의 참조로 전달된다.
- `나열`의 값은 `정수` 상수(0부터 선언 순서).

### 3.4 문장

```
문장 = 변수선언 | 대입 | 증감문 | SOV문 | 호출문 | 조건문 | 반복문 | 갈래문 | 반환문 | "탈출" 종결 | "계속" 종결 | 블록
블록 = "{" { 문장 } "}"
대입 = 좌변 대입연산자 식 종결
대입연산자 = "=" | "+=" | "-=" | "*=" | "/=" | "%=" | "&=" | "|=" | "^=" | "<<=" | ">>="
증감문 = 좌변 ("을" | "를") ("증가하다" | "감소하다") 종결        (좌변 += 1 / -= 1 과 같다)
좌변 = 이름 | 좌변 "[" 식 "]" | 좌변 "의" 이름 | 좌변 "→" 이름
```

`++`, `--`는 없다. 블록의 문장 수와 중첩 깊이에 한계는 없다.

### 3.5 SOV 문과 호출

```
SOV문  = SOV절 { 연결 SOV절 } 종결
SOV절  = { 인자 } 동사
연결   = 동사의 어미가 "고" 또는 "서"인 경우 다음 절이 이어진다: "A를 쓰기하고 B를 증가하다."
인자   = 단어(인자 위치) | 리터럴 조사 | 후위식 조사       (후위식: 괄호식, 호출식, 색인, 멤버 접근. 조사는 `)`·`]` 뒤에 붙여 쓴다)
동사   = 단어(동사 위치) | "증가하다" | "감소하다"
호출문 = 호출식 종결
호출식 = 이름 "(" [ 인자 { "," 인자 } ] ")"
인자   = 식 [ 조사 ]                        (조사는 따로 떨어진 낱말이어야 한다 — D-27)
```

연결된 절은 앞에서부터 차례로 실행되는 별개의 문장이다.

**역할 정규화.** 인자는 자기 조사의 역할로 같은 역할의 매개변수에 대응된다. 순서와 무관하다. 같은 역할이 여럿이면 표면 순서대로. 남거나 모자라면 오류. 무표 인자는 남은 매개변수에 표면 순서로. 인자는 표면 순서로 평가된다.

괄호 호출의 인자에도 역할 조사를 붙일 수 있다 (D-27). 하나라도 붙으면 동사형과 같은 역할 정규화를 쓰고,
하나도 없으면 표면 순서로 매개변수 순서에 대응한다. 두 형식의 의미 차이는 이것뿐이다.

**바꿔 쓰기 검사 (D-30).** 같은 타입인 매개변수가 둘 이상이고 역할이 다르면 그 둘을 바꿔 써도 타입이
맞는다. 호출부가 그 두 자리에 모두 조사를 안 붙이면 오류다. 둘 중 하나만 붙여도 짝이 풀린다. 제네릭 틀의
호출과 함수 값을 통한 간접 호출은 검사하지 않는다. `--dump-risky` 는 오류 대신 목록만 내는 이전용 모드다.

괄호 호출에서 조사는 **따로 떨어진 낱말**이어야 한다: `옮기기(원본 에서, 대상 으로, 3을)`. 리터럴·괄호식·
색인·호출 뒤에는 붙여 써도 된다 (`3을`, `(a + b)를`). 붙여 쓴 낱말은 쪼개지 않으므로 `재기(길이)` 의 뜻은
그대로다 — 동사형과 달리 괄호 호출은 이미 쓰이고 있어서, 이름의 뜻을 뒤늦게 바꾸지 않는다.

`1을 반환하다`, `(a + b)를 쓰다`처럼 리터럴·괄호식에 조사가 붙는 형식은 정식이다.

SOV 문의 값이 필요하면 식 위치에서 괄호로 감싼다: `정수 결과 = (5를 3에 더하다).`

### 3.6 조건문·반복문·갈래문

```
조건문 = 조건 "이면" 블록 { "아니면" 조건 "이면" 블록 } [ "아니면" 블록 ]
조건   = 식 | 단어 "보다" 단어 비교동사             (X이/가 Y보다 크면: X, Y는 인자 위치)
비교동사 = "크" | "작" | "같" | "다르" | "크거나같" | "작거나같"   (뒤에 "으면"/"면"이 붙어 이면 역할)
반복문 = "(" 식 ")" "동안" 블록
       | "반복" "(" [ 변수선언본문 | 대입본문 ] ":" 식 ":" ( 대입본문 | 증감본문 ) ")" 블록     (본문 = 종결 없는 형태)
       | "반복" "(" 타입 이름 "는" 식 "부터" 식 ( "까지" | "전까지" ) ")" 블록                (범위 반복)
       | "반복하기" 블록 "(" 식 ")" "동안" 종결
갈래문 = "갈래" "(" 식 ")" "{" { "경우" 식 ":" 블록 } [ "기본" ":" 블록 ] "}"
```

**범위 반복** (D-34) 은 세 절 형태로 펴진다. `반복 (정수 i는 a부터 b까지)`는
`반복 (정수 i = a: i <= b: i += 1)`, `…b 전까지`는 `i < b` 다. 따라서 끝 식은 되돌 때마다 다시 계산되고,
`계속`·`탈출`·중첩은 세 절 형태와 똑같이 동작한다.

`부터`·`까지`·`전까지`는 앞말에 붙여 쓰거나 띄어 쓸 수 있다 (`n부터`, `n 부터`). 렉서는 이들을 접사로
떼지 않으므로 파서가 반복 머리 안에서만 낱말 끝에서 뗀다 — 그래서 `끝까지` 라는 이름을 범위 반복의
끝 식으로 쓰면 `끝` + `까지` 로 읽힌다. 되돌거나 두 칸씩 세는 반복은 세 절 형태를 쓴다.

`계속`은 가장 안쪽 반복문으로 간다. 갈래문은 대상이 아니다. `탈출`은 가장 안쪽 반복문 또는 갈래문.
조건 자리의 식이 정수 타입이면 0이 아닐 때 참이다. 참조 타입이면 `없음`이 아닐 때 참이다.

### 3.7 반환

```
반환문 = "반환" [ 식 ] 종결 | 인자 "반환하다" 종결
```

반환 타입이 있는 함수의 모든 경로는 값을 반환해야 한다. 아니면 오류. `시작하기`의 반환값이 종료코드다.

### 3.8 식과 우선순위

- 제네릭 (D-19): 묶음과 함수는 타입 매개변수를 가질 수 있다. `묶음 목록(T)는 T 참조 자료, 정수 길이.`, `[목록(T) 참조 l에 T 값을 목록_추가(T)]는 { … }`. 타입 자리에서는 `목록(정수)`, 식 자리에서는 `목록_만들기(정수)()`처럼 인스턴스를 적는다. 호출에서 타입 인자를 생략하면 인자의 타입에서 추론한다 (`목록_추가(l, 5)`, `5를 l에 목록_추가하다`); 매개변수에 나타나지 않는 타입 매개변수는 명시해야 한다. `이름(타입, …)` 꼴은 파서가 그 이름을 제네릭 함수로 이미 알고 있을 때만 인스턴스로 읽으므로, 명시 인스턴스는 그 함수의 선언(또는 포함) 뒤에서만 쓸 수 있다. 인스턴스는 처음 쓰인 자리에서 만들어지고 이름은 `목록_추가(정수)`다. 타입 매개변수는 그 선언 안에서만 타입 이름이다.
- 결과 `T 결과` (D-18): `정수 오류`와 `T 값`을 가진 값. 오류 0 이 성공. 함수는 `-> 정수 결과`처럼 결과를 돌려주고, 본문에서 `반환 값.`(성공, 값이 암시 변환됨) 또는 `반환 오류(코드).`(실패)를 쓴다. `공허 결과`는 `반환.`이 성공이다. `시도 r`은 `r`의 오류가 0 이 아니면 그 코드로 현재 함수를 끝내고(현재 함수도 결과를 돌려줘야 한다), 아니면 값이다. `r 혹은 기본값`은 값 또는 기본값. `r의 오류`, `r의 값`. `오류(코드)`는 반환·대입·인자처럼 결과 타입이 정해진 자리에서만 쓴다. 외부 함수는 결과를 주고받을 수 없다.
- 조각 `T[]` (D-17): `T 참조 자료`와 `정수 길이`를 가진 16바이트 값. `T[N]` 배열은 조각이 필요한 자리에 암시 변환된다. `x[i:j]`는 배열·조각·참조에서 조각을 만들며 `i`·`j`는 생략할 수 있다 (`x[:n]`, `x[i:]`, `x[:]`; 참조에서는 `j` 필수). 배열·조각에서는 `0 ≤ i ≤ j ≤ 길이`, 참조에서는 `i ≤ j`를 검사한다. 조각 색인 `s[i]`는 `0 ≤ i < 길이`를 검사하고, 벗어나면 "오류: 색인 i이(가) 범위 [0, 길이) 밖입니다"를 내고 종료 코드 1 로 끝난다. `s의 길이`, `s의 자료`. 조각은 값이며(D-16 규약) 함수는 조각을 받고 돌려줄 수 있다.
- 묶음(합침 포함)은 값이다 (D-16). `a = b`, `점 p = f()`, 인자 전달, `반환 p` 는 모두 바이트 복사다. 함수 안에서 매개변수 묶음을 바꿔도 호출자의 것은 그대로다. 참조로 다루려면 `점 참조`. 배열은 값이 아니다: 대입·반환할 수 없고 참조로 붕괴한다. 외부 함수는 묶음을 값으로 주고받을 수 없다.
- 이항 연산에서 리터럴은 상대 피연산자의 타입을 따른다. 그 타입에 들어가지 않는 정수 리터럴은 정수(64비트)로 보고 상대를 넓힌다: `문자값 & 255`는 정수다. 선언·대입·인자처럼 목표 타입이 정해진 자리에서는 여전히 범위 오류다.

```
식 = 삼항
삼항 = 또는식 [ "?" 식 ":" 식 ]
또는식 = 그리고식 { "또는" 그리고식 }
그리고식 = 비트합 { "그리고" 비트합 }
… (표의 순서대로)
단항 = ( "-" | "아닌" | "~" | "&" ) 단항 | "크기" "(" 타입 ")" | 변환
변환 = 후위 [ "으로" 타입 | "로" 타입 ]
후위 = 기본 { "[" 식 "]" | "의" 이름 | "→" 이름 | "(" [ 식 { "," 식 } ] ")" }
기본 = 이름 | 리터럴 | "(" 식 ")" | "(" SOV문본문 ")"
```

| 순위 | 연산자 | 결합 |
|---|---|---|
| 1 | 후위 `[]` `의` `→` 호출 | 좌 |
| 2 | 단항 `-` `아닌` `~` `&` `크기()` | 우 |
| 3 | 변환 `으로/로 타입` | 좌 |
| 4 | `*` `/` `%` | 좌 |
| 5 | `+` `-` | 좌 |
| 6 | `<<` `>>` | 좌 |
| 7 | `<` `>` `<=` `>=` | 좌 |
| 8 | `==` `!=` | 좌 |
| 9 | `&` | 좌 |
| 10 | `^` | 좌 |
| 11 | `\|` | 좌 |
| 12 | `그리고` | 좌, 단락 |
| 13 | `또는` | 좌, 단락 |
| 14 | `? :` | 우 |

- `-a[0]`은 `-(a[0])`.
- 가변 인자 함수를 정의할 수 있다: 헤더의 마지막 매개변수 자리에 `...`. 본문에서는 `가변인자(k)`로 k 번째(0부터) 추가 인자를 64비트 원시 값(정수)으로 읽는다. 호출자는 실수를 배정밀도로, 정수를 64비트로 올려 넘기므로 실수는 `합침`으로 비트를 해석한다. 개수는 넘어오지 않는다 — 서식 문자열이나 개수 인자로 알린다. `가변인자`는 가변 인자 함수 안에서만 쓸 수 있고, 같은 이름의 함수를 선언하면 그것이 우선한다.
- 호출 `f(x)`와 색인 `a[i]`의 여는 괄호는 앞 식에 공백 없이 붙여 쓴다. 띄어 쓴 `(`·`[`는 후위 연산자가 아니다.
- 대입 `대상 = 식.`은 대상의 주소를 먼저 계산하고 식을 평가한 뒤 저장한다. 식이 대상이 들어 있는 저장소를 옮길 수 있으면(예: `동적배열` 원소를 가리키는 대상에 그 배열을 늘리는 호출 결과를 대입) 결과는 옛 주소에 쓰인다 — 그런 경우 값을 먼저 지역 변수에 받는다.
- 절 중간에 문장 키워드나 타입 키워드가 오면 "문장 끝에 `.` 필요" 오류다 (선언·문장이 `.` 없이 이어진 것). 단, 변환의 대상 타입(`로/으로` 바로 뒤의 타입 키워드, `부호없는` 포함)은 예외다.
- 변환 `식으로 타입`/`식로 타입`의 타입은 타입 키워드나 타입 이름으로 시작한다. `[`로 시작하는 함수 타입으로의 변환은 없다 (`경로[k]`처럼 `로`로 끝나는 이름의 색인과 구분하기 위해).
- 단항 `*`는 없다. 포인터 역참조는 색인 `p[0]`. 묶음 포인터의 멤버는 `p→필드`이고, `p→필드의 하위`처럼 `의` 연쇄를 이을 수 있다 (이름은 `의`로 끝날 수 없으므로 모호하지 않다).
- `&`는 좌변이 될 수 있는 식의 주소.
- 비교와 논리 연산의 결과 타입은 `참거짓`.

### 3.9 문자열 보간

`"{식}"`은 식의 값으로 치환되며 서식은 식의 타입이 정한다 (정수 `%lld`, 부호없는 `%llu`, 실수 `%f`, 문자열 `%s`, 문자 `%c`, 참거짓 `%d`). 중괄호 안에는 아무 식이나 올 수 있다 — `"{a + b}"`, `"{두배(a)}"`, `"{v[i]}"`, `"{p의 x}"`, `"{(a로 실수)}"`, `"{(a를 두배하다)}"` (D-35). 파서가 중괄호 안을 따로 토큰화해 식으로 읽으므로 그 안에서는 문장이 아니라 식 하나여야 하고, 오류의 줄·열은 원문의 자리를 가리킨다. 중괄호 안에 문자열 리터럴은 쓸 수 없다 — 따옴표가 바깥 리터럴을 먼저 끝내기 때문이다. 보간이 있는 문자열 리터럴은 **가변 인자 함수의 서식 자리**, 곧 마지막 고정 매개변수에서만 허용되고, 추가 서식 인자와 섞을 수 없다(오류). `쓰기`(`[문자열 형식을 ... 쓰기]`)뿐 아니라 `버퍼에_쓰기`(`[문자열 버퍼에 정수 길이로 문자열 형식을 ... 버퍼에_쓰기]`)와 `파일에_쓰기` 도 여기에 해당한다. 리터럴 중괄호는 `\{`, `\}`.

## 4. 의미 규칙

- 이름 해석: 선언 전 사용은 오류. 섀도잉은 안쪽 블록에서만.
- 타입 검사: 초기화·대입·인자·반환의 타입은 3.3 규칙. 불일치는 오류. 인자 개수·역할 불일치는 오류.
- 배열 경계: 검사하지 않는다.
- 초기화되지 않은 지역 변수 읽기: 정의되지 않은 동작.
- 정수 오버플로: 2의 보수 순환. 0으로 나누기: 정의되지 않은 동작.
- 정적 지역 변수: 프로그램 시작 시 한 번 초기화, 호출 간 유지.

## 5. 프로그램 시작과 종료

- 진입점은 `[시작하기]` 또는 `[정수 argc를 문자열 참조 argv를 시작하기]`. 정확히 하나.
- argv는 UTF-8. 시작 코드가 콘솔 출력 코드페이지를 UTF-8로 설정하고 종료 시 복원한다.
- 컴파일러는 사용자 프로그램에 사용자가 쓰지 않은 호출을 삽입하지 않는다.

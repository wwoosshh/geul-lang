# 덤프 형식

참조 구현(`ref/`)과 자체호스팅 구현(`self/`)이 단계마다 같은 문자열을 내야 한다. 이 문서가 그 형식의 명세다. 형식을 바꾸면 두 구현과 이 문서를 같이 바꾼다.

## 토큰 덤프 — `geulc --dump-tokens 파일.gl`

한 토큰에 한 줄. 탭으로 구분한 세 칸: `줄:열`, 종류, 원문.

```
1:1	키워드	포함
1:4	문자열리터럴	"표준/기본.gl"
2:1	기호	[
2:2	키워드	시작하기
2:6	기호	]
2:7	접사	는
2:9	기호	->
2:12	키워드	정수
2:15	기호	{
3:5	문자열리터럴	"안녕\n"
3:12	접사	을
3:14	단어	쓰다
3:16	종결	.
4:1	기호	}
5:1	끝	
```

- 종류: `단어` `식별자` `키워드` `접사` `정수리터럴` `실수리터럴` `문자리터럴` `문자열리터럴` `기호` `종결` `끝` (명세 2.1).
- 원문은 소스에 적힌 그대로다. 문자열·문자 리터럴은 따옴표와 이스케이프를 포함한 원문. 정수 리터럴은 밑줄·`0x` 를 포함한 원문. `→` 기호는 `->` 로 낸다 (어휘 별칭). `끝`의 원문은 빈 칸.
- 열은 코드포인트 단위, 1부터. 줄 끝은 LF 로 정규화한 뒤의 위치.
- 마지막 줄 뒤에 줄바꿈을 두지 않는다.

## 구문 트리 덤프 — `geulc --dump-ast 파일.gl`

주어진 파일 하나의 트리. 포함 파일은 타입 이름을 빌리기 위해 파싱만 하고 덤프에는 넣지 않는다.

한 노드에 한 줄. 들여쓰기는 공백 두 칸이 한 단계. 줄 모양:

```
[필드이름: ]노드종류[ 필드=값 ...]
```

- 스칼라 필드(정수·실수·문자열·참거짓)는 같은 줄에 `이름=값` 로, 노드 클래스의 필드 순서대로. `None`인 필드와 빈 목록은 생략. 참거짓은 `참`/`거짓`. 실수는 파이썬 `repr` 과 같은 최단 표기.
- 노드·목록 필드는 다음 줄들에 한 단계 들여 쓴 `필드이름: ...` 로. 목록은 `필드이름: [개수]` 줄 뒤에 원소들이 한 단계 더 들여 쓰여 온다. 쌍(조건, 블록)은 `[2]` 목록으로 낸다.
- 문자열 리터럴은 `문자열 "원문"` (따옴표·이스케이프 포함 원문). 실수 리터럴도 `실수 원문` (음수로 접힌 것은 `-` 를 앞에 붙인 원문). 정수·문자 리터럴은 `값=N` (밑줄·16진은 값으로 환산, 음수 접힘 포함).
- SOV 호출의 인자는 `[2]` 아래에 식 노드와 역할 이름(`대상`·`목적지`·`출처`·`수단`·`동반`, 없으면 `무표`)이 온다. 묶음 필드는 `[2]` 아래에 타입 노드와 이름이 온다.
- 위치(줄·열)는 덤프하지 않는다.

노드 종류와 필드 이름:

| 노드 | 필드 (순서대로) |
|---|---|
| 프로그램 | 포함, 선언 |
| 변수선언 | 타입, 이름, 초기값, 정적, 상수 |
| 함수정의 | 이름, 매개변수, 반환타입, 본문, 링크이름, 가변 |
| 매개변수 | 타입, 이름, 역할 |
| 묶음선언 | 이름, 필드(타입·이름 쌍의 목록), 합침 |
| 나열선언 | 이름, 값 |
| 별칭선언 | 이름, 타입 |
| 블록 | 문장 |
| 식문 | 식 |
| 대입 | 대상, 연산자, 값 |
| 증감 | 대상, 증분 |
| 조건문 | 조건, 참블록, 아니면조건(조건·블록 쌍 목록), 아니면블록 |
| 동안 | 조건, 본문 |
| 반복 | 초기값, 조건, 증감, 본문 |
| 반복하기 | 본문, 조건 |
| 갈래 | 대상, 경우(값·블록 쌍 목록), 기본 |
| 반환 | 값 |
| 탈출, 계속 | — |
| 정수, 실수, 문자 | 값 |
| 문자열 | 원문 |
| 참거짓 | 값 |
| 없음 | — |
| 이름 | 이름 |
| 색인 | 바탕, 색인 |
| 멤버 | 바탕, 이름, 화살표 |
| 호출 | 피호출, 인자 |
| SOV호출 | 인자(식·역할 쌍 목록), 동사 |
| 단항 | 연산자, 피연산자 |
| 이항 | 연산자, 좌, 우 |
| 삼항 | 조건, 참값, 거짓값 |
| 변환 | 식, 타입 |
| 크기 | 타입 |
| 기본타입 | 이름, 부호없는 |
| 이름타입 | 이름 |
| 참조타입 | target(대상 타입) |
| 배열타입 | 원소, 크기 |
| 함수타입 | 매개변수, 반환타입 |

예:

```
프로그램
  포함: [1]
    포함 "표준/기본.gl"
  선언: [1]
    함수정의 이름=시작하기 가변=거짓
      반환타입: 기본타입 이름=정수 부호없는=거짓
      본문: 블록
        문장: [2]
          식문
            식: SOV호출 동사=쓰
              인자: [1]
                [2]
                  문자열 "안녕\n"
                  대상
          반환
            값: 정수 값=0
```

`포함` 항목은 `포함 "파일이름"` 한 줄이다. 참거짓 필드는 값이 거짓이어도 낸다(`가변=거짓`, `정적=거짓 상수=거짓`).

## IR 덤프 — `geulc --dump-ir 파일.gl`

포함 처리와 의미 분석을 거친 전체 프로그램(표준 라이브러리 포함)의 타입 IR. 순서대로:

```
외부 <dll> <링크이름>: <함수타입>          외부 선언 순서대로 (dll 은 링크 이름으로 정한다: kernel32·shell32 목록에 있으면 그것, 아니면 msvcrt.dll)
전역 <이름>: <타입> = <초기값>             선언 순서. 초기값: 없음 | 정수 | 실수상수 0x<IEEE 비트> | 문자열 #k
문자열 #k "<정규 이스케이프>"             문자열 풀. 전역 초기값의 문자열이 먼저, 그다음 함수 본문 등장 순
진입 시작하기
함수 <이름>(<매개>: <타입>, ...) -> <반환타입|공허>
  지역 <이름>: <타입>                      매개변수를 제외한 지역 변수, 선언 순서 (정적 지역은 <함수>.<이름>.<번호>)
  <라벨>:                                  라벨은 .<함수>.<힌트><번호>
    %n: <타입> = <명령> ...                값을 내는 명령
    <명령> ...                             값을 내지 않는 명령
```

명령:

| 형식 | 뜻 |
|---|---|
| `%n: T = 상수 V` | 정수 상수 (음수는 `-` 포함) |
| `%n: T = 실수상수 0x…` | 실수 상수, IEEE 비트를 16진 (64비트 16자리, 32비트 8자리) |
| `%n: T = 문자열 #k` | 문자열 풀 참조 |
| `%n: T = 지역주소 이름` / `전역주소 이름` | 변수 주소 |
| `%n: T = 함수주소 이름` / `외부함수주소 링크이름` | 함수 값 |
| `%n: T = 복사 %a` | |
| `%n: T = 적재 %addr` | T 크기로 읽기 |
| `저장 %addr <- %src : T` | T 크기로 쓰기 |
| `%n: T = 오프셋 %base + k` | 묶음 필드 주소 |
| `%n: T = 원소주소 %base + %idx * 크기` | 배열·참조 색인 주소 |
| `%n: T = 이항 op %a %b` | op: add sub mul sdiv udiv srem urem and or xor shl lshr ashr fadd fsub fmul fdiv |
| `%n: 참거짓 = 비교 cond %a %b : T` | cond: eq ne lt le gt ge ult ule ugt uge feq fne flt fle fgt fge (T 는 피연산자 타입) |
| `%n: T = 부호반전 %a` / `비트반전 %a` / `논리부정 %a : T` | |
| `%n: T = 변환 kind %a` | kind: sext zext trunc sitofp uitofp fptosi fpext fptrunc |
| `%n: 정수 = 가변인자 %k` | 가변 인자 함수의 k 번째 추가 인자 (홈 슬롯 [rbp+16+8·(고정 수+k)]) |
| `복사메모리 %대상 <- %원본 : 크기` | 묶음 값 복사 (D-16). 묶음을 값으로 돌려주는 함수는 숨은 첫 매개변수 `__결과: T 참조` 를 받고 IR 반환 타입은 공허다; 호출자는 `__반환n`·`__복사n` 지역 자리를 만든다 |
| `%n: T = 호출 이름(%a, ...)` / `외부호출 링크이름(...)` / `호출 %f(...)` | 값 없는 호출은 `%n: T =` 없이 |
| `점프 라벨` / `분기 %c ? 참라벨 : 거짓라벨` / `반환 %v` / `반환` | |

타입 표기는 명세 3.3의 이름. 이름 없는 정수 타입(연산 결과)은 폭으로 `작은정수·짧은정수·중간정수·정수`(부호없으면 `부호없는 ` 접두). `문자 참조`는 `문자열`. 함수 타입은 `[매개, ... -> 반환]`(반환 없으면 `-> ` 뒤가 빈 칸).

임시값 번호와 라벨 번호는 하강 순서로 매겨지므로, 자체호스팅 구현은 참조 구현과 같은 순서로 임시값·라벨을 만들어야 한다. 문자열 풀의 정규 이스케이프: `\n \t \r \0 \\ \"`, 그 외 바이트는 그대로.

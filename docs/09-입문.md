# 글 입문

프로그래밍을 한국어로 해 보는 안내서다. 열네 장이고, 각 장에 돌아가는 프로그램이 하나씩 있다.
**여기 있는 모든 예제는 빌드할 때 실제로 컴파일하고 실행해서 결과를 맞춰 본다.** 문서가 낡으면
빌드가 깨진다.

앞선 지식은 필요 없다. 다른 언어를 안다면 훑어 읽으면서 다른 점만 봐도 된다. 명세가 궁금해지면
`03-문법-명세.md` 로 가면 되지만, 이 문서만 읽어도 프로그램을 쓸 수 있다.

준비물은 `geulc.exe` 와 그 옆의 `표준/` 폴더뿐이다. 설치할 것은 없다.

---

## 1장. 첫 프로그램

파일 하나를 만들고 `안녕.gl` 이라고 이름 붙인다.

```글
[시작하기]는 -> 정수 {
    "안녕, 글!\n"을 쓰다.
    반환 0.
}
```

```출력
안녕, 글!
```

만든 뒤 이렇게 실행한다.

```
geulc 안녕.gl
안녕.exe
```

읽는 법을 하나씩 보자.

- `[시작하기]는` 이 함수의 머리다. 대괄호 안이 이름이고, 프로그램은 항상 `시작하기` 에서 출발한다.
- `-> 정수` 는 이 함수가 정수를 돌려준다는 뜻이다. 프로그램의 종료 코드가 된다.
- `"안녕, 글!\n"을 쓰다.` 가 실제로 하는 일이다. **한국어 어순 그대로 목적어가 앞에 오고 동사가
  뒤에 온다.** `\n` 은 줄바꿈이다.
- 문장은 마침표로 끝난다. 세미콜론이 아니라 마침표다.
- `반환 0.` 으로 0 을 돌려준다. 0 은 "잘 끝났다" 는 뜻이다.

## 2장. 값을 담는 상자

값을 담아 두려면 타입과 이름을 적는다.

```글
[시작하기]는 -> 정수 {
    정수 나이 = 15.
    실수 키 = 172.5.
    문자열 이름 = "가나".
    참거짓 학생인가 = 참.

    "{이름}는 {나이}살, 학생인가 {학생인가}\n"을 쓰다.
    "키 %g\n"을 키를 쓰다.
    반환 0.
}
```

```출력
가나는 15살, 학생인가 1
키 172.5
```

타입은 이런 것들이 있다.

| 타입 | 담는 것 |
|---|---|
| `정수` | -9경에서 9경까지의 정수 |
| `실수` | 소수점이 있는 수 |
| `문자열` | 글자들 |
| `참거짓` | `참` 또는 `거짓` |
| `문자` | 글자 하나 (아스키) |

값은 **중괄호로 문장 안에 끼워 넣는다.** `"{이름}는 {나이}살"` 처럼 쓰면 읽는 순서대로 적힌다.
중괄호 안에는 이름뿐 아니라 어떤 식이든 올 수 있다 — `{a + b}`, `{두배(a)}`, `{점수[0]}`, `{사람의 나이}`.

두 가지만 예외다. 중괄호 안에 **문자열 리터럴은 넣을 수 없고**(따옴표가 바깥 문자열을 끝내 버린다),
실수는 `172.500000` 처럼 소수점 아래가 길게 찍힌다. 그럴 때는 값을 조사로 잇고 `%` 자리 표시를 쓴다 —
`%lld` 정수, `%g`·`%f` 실수, `%s` 문자열, `%d` 참거짓, `%c` 문자. 위 예의 `키` 가 그런 경우다.

값을 바꿀 수 없게 하려면 앞에 `상수` 를 붙인다.

```글
[시작하기]는 -> 정수 {
    상수 정수 최대 = 100.
    "최대는 {최대}\n"을 쓰다.
    반환 0.
}
```

```출력
최대는 100
```

## 3장. 셈하기

사칙연산은 익숙한 기호를 쓴다.

```글
[시작하기]는 -> 정수 {
    정수 a = 17.
    정수 b = 5.
    "{a} + {b} = {(a + b)}\n"을 쓰다.
    "{a} - {b} = {(a - b)}\n"을 쓰다.
    "{a} * {b} = {(a * b)}\n"을 쓰다.
    "{a} / {b} = {(a / b)}\n"을 쓰다.
    "{a} % {b} = {(a % b)}\n"을 쓰다.
    반환 0.
}
```

```출력
17 + 5 = 22
17 - 5 = 12
17 * 5 = 85
17 / 5 = 3
17 % 5 = 2
```

정수끼리 나누면 몫만 남는다. `%` 는 나머지다. 서식 문자열 안에서 `%` 한 글자를 찍으려면 `%%` 처럼
두 번 적는다.

식에 조사를 붙일 때는 괄호로 감싼다. `(a + b)를` 처럼 쓴다.

실수로 나누고 싶으면 실수로 바꾼다.

```글
[시작하기]는 -> 정수 {
    정수 a = 17.
    정수 b = 5.
    실수 몫 = (a로 실수) / (b로 실수).
    "{몫}\n"을 쓰다.
    반환 0.
}
```

```출력
3.400000
```

`값으로 타입` 이 변환이다. `로` 와 `으로` 둘 다 쓸 수 있다.

## 4장. 갈림길

조건에 따라 다르게 하려면 `이면` 을 쓴다.

```글
[시작하기]는 -> 정수 {
    정수 점수 = 78.

    점수 >= 90이면 { "수\n"을 쓰다. }
    아니면 점수 >= 80이면 { "우\n"을 쓰다. }
    아니면 점수 >= 70이면 { "미\n"을 쓰다. }
    아니면 { "양\n"을 쓰다. }

    반환 0.
}
```

```출력
미
```

비교는 `==` `!=` `<` `>` `<=` `>=` 이고, 여럿을 잇는 말은 `그리고` `또는` `아닌` 이다.

```글
[시작하기]는 -> 정수 {
    정수 나이 = 15.
    참거짓 방학인가 = 참.

    (나이 >= 13 그리고 나이 <= 19)이면 { "청소년\n"을 쓰다. }
    (방학인가 또는 나이 < 8)이면 { "쉬는 날\n"을 쓰다. }
    아닌 방학인가이면 { "학교 가는 날\n"을 쓰다. }

    반환 0.
}
```

```출력
청소년
쉬는 날
```

## 5장. 되풀이

정해진 횟수만큼 되풀이하려면 `반복` 에 범위를 준다.

```글
[시작하기]는 -> 정수 {
    반복 (정수 i는 1부터 5까지) {
        "{i}번째\n"을 쓰다.
    }
    반환 0.
}
```

```출력
1번째
2번째
3번째
4번째
5번째
```

`1부터 5까지` 는 말 그대로 1, 2, 3, 4, 5 다. 끝을 포함하지 않으려면 `전까지` 를 쓴다 —
`0부터 5 전까지` 는 0, 1, 2, 3, 4 다. 그릇을 훑을 때는 대개 이쪽이다.

```글
[시작하기]는 -> 정수 {
    반복 (정수 i는 0부터 3 전까지) {
        "{i} "을 쓰다.
    }
    "\n"을 쓰다.
    반환 0.
}
```

```출력
0 1 2 
```

되돌거나 두 칸씩 세는 반복은 세 부분을 콜론으로 나눠 직접 적는다. 처음 값, 계속할 조건,
한 바퀴 끝날 때 할 일이다.

```글
[시작하기]는 -> 정수 {
    반복 (정수 i = 10: i > 0: i -= 3) {
        "{i} "을 쓰다.
    }
    "\n"을 쓰다.
    반환 0.
}
```

```출력
10 7 4 1 
```

조건만으로 도는 `동안` 도 있다.

```글
[시작하기]는 -> 정수 {
    정수 남은돈 = 1000.
    정수 산개수 = 0.

    (남은돈 >= 300)동안 {
        남은돈 = 남은돈 - 300.
        산개수를 증가하다.
    }

    "{산개수}개 사고 {남은돈}원 남음\n"을 쓰다.
    반환 0.
}
```

```출력
3개 사고 100원 남음
```

`증가하다` 와 `감소하다` 는 1 을 더하고 빼는 예약된 말이다. 도중에 빠져나오려면 `탈출`, 다음
바퀴로 건너뛰려면 `계속` 을 쓴다.

```글
[시작하기]는 -> 정수 {
    반복 (정수 i는 1부터 10까지) {
        i % 2 == 0이면 { 계속. }
        i > 7이면 { 탈출. }
        "{i} "을 쓰다.
    }
    "\n"을 쓰다.
    반환 0.
}
```

```출력
1 3 5 7 
```

## 6장. 함수 만들기

같은 일을 여러 번 한다면 이름을 붙여 둔다.

```글
[정수 값을 두배]는 -> 정수 {
    반환 값 * 2.
}

[시작하기]는 -> 정수 {
    "{두배(5)} {두배(21)}\n"을 쓰다.
    반환 0.
}
```

```출력
10 42
```

함수 머리를 다시 보자. `[정수 값을 두배]는` 에서 `정수 값을` 이 매개변수다. **이름 뒤에 붙은
조사가 중요하다.** `값을` 의 `을` 이 이 자리의 역할을 정한다.

그래서 이 함수는 두 가지 방법으로 부를 수 있다.

```글
[정수 값을 두배]는 -> 정수 { 반환 값 * 2. }

[시작하기]는 -> 정수 {
    "{두배(5)}\n"을 쓰다.
    5를 두배하다.
    "{(5를 두배하다)}\n"을 쓰다.
    반환 0.
}
```

```출력
10
10
```

`두배(5)` 는 괄호 호출이고 `5를 두배하다` 는 동사형 호출이다. 동사형은 한국어 문장처럼 읽힌다.
값이 필요한 자리에서는 괄호로 감싼다.

동사형에서 `두배` 가 `두배하다` 가 되는 규칙은 간단하다. `~하다` 를 쓰면 컴파일러가 `~하기`,
`~`, 어간 순서로 함수를 찾는다. `쓰기` 를 `쓰다` 로 부르는 것도 같은 규칙이다.

여러 값을 받는 함수를 만들어 보자.

```글
[정수 a를 정수 b와 더하기]는 -> 정수 {
    반환 a + b.
}

[시작하기]는 -> 정수 {
    "{(3을 4와 더하다)}\n"을 쓰다.
    "{더하기(3, 4 와)}\n"을 쓰다.
    반환 0.
}
```

```출력
7
7
```

## 7장. 조사가 하는 일

여기가 글이 다른 언어와 가장 다른 곳이다. 이 함수를 보자.

```글
[문자열 원본에서 문자열 대상으로 정수 개수를 옮기기]는 -> 정수 {
    "{원본}에서 {대상}로 {개수}개\n"을 쓰다.
    반환 개수.
}

[시작하기]는 -> 정수 {
    3을 "서울"에서 "부산"으로 옮기다.
    "부산"으로 3을 "서울"에서 옮기다.
    "서울"에서 "부산"으로 3을 옮기다.
    반환 0.
}
```

```출력
서울에서 부산로 3개
서울에서 부산로 3개
서울에서 부산로 3개
```

**세 줄이 모두 같은 호출이다.** 순서를 바꿔도 결과가 같다. 조사가 어느 값이 어느 자리로 가는지
말해 주기 때문이다. `~에서` 는 출처, `~으로` 는 수단, `~을` 은 대상이다.

다른 언어에서는 `옮기기("서울", "부산", 3)` 처럼 순서로만 구별한다. 그래서 순서를 헷갈리면
조용히 잘못 동작한다. `substring(시작, 끝)` 과 `substr(시작, 길이)` 를 헷갈리는 것이 그런 예다.

### 표준 라이브러리도 이렇게 부른다

표준 라이브러리의 이름에는 앞에 모듈이 붙어 있다 — `정수목록_추가`, `사전_넣기`, `파일_닫기`.
동사형으로 부를 때는 **앞부분을 떼고 부른다.**

```글
포함 "표준/목록.gl"
포함 "표준/문자열.gl"

[시작하기]는 -> 정수 {
    정수목록 참조 수들 = 정수목록_만들기().
    수들에 3을 추가하다.
    수들에 5를 추가하다.

    문자열목록 참조 말들 = 문자열목록_만들기().
    말들에 "가"를 추가하다.

    "{정수목록_길이(수들)} {정수목록_값(수들, 1)} {문자열목록_길이(말들)}\n"을 쓰다.
    반환 0.
}
```

```출력
2 5 1
```

`추가하다` 하나로 두 그릇을 다뤘다. **받는 것의 타입이 어느 함수인지 정해 준다** — `수들`이
`정수목록 참조`면 `정수목록_추가`, `말들`이 `문자열목록 참조`면 `문자열목록_추가` 다.
어느 쪽인지 정해지지 않으면 컴파일러가 후보를 적어 주며 멈춘다.

글은 이것을 아예 막는다. 같은 타입인 두 자리를 바꿔 쓸 수 있는데 조사를 안 붙이면 컴파일이
거부한다. 위 함수를 `옮기기("서울", "부산", 3)` 이라고 부르면 이런 말이 나온다.

```
오류: '옮기기' 호출에서 두 인자를 바꿔 써도 컴파일됩니다: '원본'(에서), '대상'(로)
     — 둘 중 하나에 역할 조사를 붙여 구별하세요
```

쓸 수 있는 조사는 다섯 가지다.

| 조사 | 역할 | 뜻 |
|---|---|---|
| `을` `를` | 대상 | 무엇을 |
| `에` | 목적지 | 어디로 |
| `에서` | 출처 | 어디서 |
| `로` `으로` | 수단 | 무엇으로 |
| `와` `과` | 동반 | 무엇과 |

괄호 호출에서 조사를 붙일 때는 **띄어 쓴다**. `옮기기(원본 에서, 대상 으로, 3을)` 처럼 쓴다.
붙여 쓰면 이름의 일부로 읽는다. 리터럴 뒤에는 붙여 써도 된다.

## 8장. 여러 값을 한 줄에

같은 타입의 값을 여럿 담으려면 배열을 쓴다.

```글
[시작하기]는 -> 정수 {
    정수[5] 점수.
    점수[0] = 90. 점수[1] = 85. 점수[2] = 78. 점수[3] = 92. 점수[4] = 66.

    정수 합 = 0.
    반복 (정수 i는 0부터 5 전까지) {
        합 = 합 + 점수[i].
    }
    "합 %lld, 평균 %g\n"을 합을 ((합로 실수) / 5.0)을 쓰다.
    반환 0.
}
```

```출력
합 411, 평균 82.2
```

자리 번호는 0 부터 센다. 배열의 크기는 만들 때 정해지고 바뀌지 않는다.

배열을 함수에 넘기려면 **조각**을 쓴다. 조각은 "어디서부터 몇 개" 를 함께 들고 다니는 값이다.

```글
[정수[] 자료를 합계]는 -> 정수 {
    정수 합 = 0.
    반복 (정수 i는 0부터 자료의 길이 전까지) {
        합 = 합 + 자료[i].
    }
    반환 합.
}

[시작하기]는 -> 정수 {
    정수[5] 점수.
    반복 (정수 i는 0부터 5 전까지) { 점수[i] = (i + 1) * 10. }

    "전체 {합계(점수)}\n"을 쓰다.
    "앞 셋 {합계(점수[0:3])}\n"을 쓰다.
    반환 0.
}
```

```출력
전체 150
앞 셋 60
```

`정수[]` 가 조각 타입이다. 배열은 조각이 필요한 자리에 저절로 바뀐다. `자료의 길이` 로 개수를
알 수 있고, `점수[0:3]` 은 0 번부터 3 번 앞까지를 잘라 낸다.

범위를 벗어나면 프로그램이 멈추면서 그 사실을 알려 준다. 조용히 엉뚱한 값을 읽지 않는다.

## 9장. 여러 값을 하나로 — 묶음

성격이 다른 값들을 한 덩어리로 다루려면 묶음을 만든다.

```글
묶음 학생은 문자열 이름, 정수 나이, 실수 평점.

[학생 참조 s를 소개]는 {
    "%s (%lld살, 평점 %g)\n"을 s→이름을 s→나이를 s→평점을 쓰다.
}

[시작하기]는 -> 정수 {
    학생 가나.
    가나의 이름 = "가나".
    가나의 나이 = 15.
    가나의 평점 = 4.2.

    소개(&가나).

    학생 다라 = 가나.
    다라의 이름 = "다라".
    소개(&다라).
    소개(&가나).
    반환 0.
}
```

```출력
가나 (15살, 평점 4.2)
다라 (15살, 평점 4.2)
가나 (15살, 평점 4.2)
```

`가나의 이름` 처럼 `의` 로 필드에 닿는다. 참조를 통할 때는 `s→이름` 처럼 화살표를 쓴다.

마지막 줄이 중요하다. `학생 다라 = 가나.` 는 **복사**다. 다라의 이름을 바꿔도 가나는 그대로다.
묶음은 값이다. 원본을 바꾸고 싶으면 `&가나` 처럼 참조를 넘긴다.

## 10장. 글자 다루기

문자열을 다루는 함수는 `표준/문자열.gl` 에 있다. 쓰려면 파일 맨 위에 `포함` 을 적는다.

```글
포함 "표준/문자열.gl"

[시작하기]는 -> 정수 {
    문자열 말 = "글로 쓰는 프로그램".

    "길이 {글자수(말)} 바이트, {한글_글자수(말)} 글자\n"을 쓰다.
    "%d %d\n"을 문자열_시작하는가(말, "글로" 로)를 문자열_끝나는가(말, "프로그램" 로)를 쓰다.

    문자열 바뀜 = 문자열_바꾸기(말 에서, "글" 을, "한글").
    "{바뀜}\n"을 쓰다.

    문자열목록 참조 조각들 = 문자열_나누기(말, " " 로).
    반복 (정수 i는 0부터 문자열목록_길이(조각들) 전까지) {
        "[{문자열목록_값(조각들, i)}]"을 쓰다.
    }
    "\n"을 쓰다.

    해제(바뀜).
    문자열목록_해제(조각들).
    반환 0.
}
```

```출력
길이 26 바이트, 10 글자
1 1
한글로 쓰는 프로그램
[글로][쓰는][프로그램]
```

한글 한 글자는 3 바이트다. 그래서 `글자수` 와 `한글_글자수` 가 다르다.

새로 만들어진 문자열과 목록은 다 쓰면 `해제` 한다. 글에는 자동 회수가 없다.

## 11장. 늘어나는 그릇

개수를 미리 모르는 값들은 목록에 담는다.

```글
포함 "표준/목록.gl"

[시작하기]는 -> 정수 {
    정수목록 참조 수들 = 정수목록_만들기().

    반복 (정수 i는 1부터 5까지) {
        수들에 i * i를 추가하다.
    }

    정수 합 = 0.
    반복 (정수 i는 0부터 정수목록_길이(수들) 전까지) {
        합 = 합 + 정수목록_값(수들, i).
    }

    "{정수목록_길이(수들)}개, 합 {합}\n"을 쓰다.
    정수목록_해제(수들).
    반환 0.
}
```

```출력
5개, 합 55
```

이름으로 값을 찾으려면 사전을 쓴다.

```글
포함 "표준/사전.gl"

[시작하기]는 -> 정수 {
    사전 참조 나이 = 사전_만들기().

    나이에 "가나"로 15를 넣다.
    나이에 "다라"로 17을 넣다.

    "가나 %lld살\n"을 사전_값(나이, "가나")을 쓰다.
    "%d %d\n"을 사전_있는가(나이, "다라")를 사전_있는가(나이, "마바")를 쓰다.

    사전_해제(나이).
    반환 0.
}
```

```출력
가나 15살
1 0
```

어떤 타입이든 담는 `목록(T)` 도 있다. `표준/일반목록.gl` 을 포함하면 쓸 수 있다.

```글
포함 "표준/일반목록.gl"

묶음 점은 정수 x, 정수 y.

[시작하기]는 -> 정수 {
    목록(점) 참조 점들 = 목록_만들기(점)().

    점 p. p의 x = 3. p의 y = 4.
    목록_추가(점들, p).
    p의 x = 30.
    목록_추가(점들, p).

    반복 (정수 i는 0부터 목록_길이(점들) 전까지) {
        "({목록_값(점들, i)의 x}, {목록_값(점들, i)의 y}) "을 쓰다.
    }
    "\n"을 쓰다.
    목록_해제(점들).
    반환 0.
}
```

```출력
(3, 4) (30, 4) 
```

## 12장. 파일 읽고 쓰기

파일은 열고, 쓰거나 읽고, 닫는다.

```글
포함 "표준/입출력.gl"

[시작하기]는 -> 정수 {
    공허 참조 f = 파일_열기("메모.txt" 를, "w").
    f == 없음이면 { "열 수 없음\n"을 쓰다. 반환 1. }
    파일에_쓰기(f, "첫 줄\n").
    파일에_쓰기(f, "둘째 줄 %lld\n", 42).
    f를 닫다.

    공허 참조 g = 파일_열기("메모.txt" 를, "r").
    문자[256] 줄.
    (줄_읽기(줄, 256, g) != 없음)동안 {
        "읽음: {줄}"을 쓰다.
    }
    g를 닫다.
    파일_삭제("메모.txt").
    반환 0.
}
```

```출력
읽음: 첫 줄
읽음: 둘째 줄 42
```

`파일_열기` 의 두 번째 인자는 모드다. `"r"` 은 읽기, `"w"` 는 쓰기, `"a"` 는 이어 쓰기다.
경로와 모드가 둘 다 문자열이라 조사를 붙여 구별했다.

`줄_읽기` 는 한 줄을 읽어 버퍼에 넣고, 더 읽을 것이 없으면 `없음` 을 돌려준다.

## 13장. 실패를 값으로 다루기

실패할 수 있는 함수는 **결과** 타입을 돌려준다.

```글
[문자열 글월을 정수로_바꾸기]는 -> 정수 결과 {
    정수 n = 글자수(글월).
    n == 0이면 { 반환 오류(1). }

    정수 값 = 0.
    반복 (정수 i는 0부터 n 전까지) {
        (글월[i] < 48 또는 글월[i] > 57)이면 { 반환 오류(2). }
        값 = 값 * 10 + (글월[i] - 48).
    }
    반환 값.
}

[문자열 글월을 두배로]는 -> 정수 결과 {
    정수 v = 시도 정수로_바꾸기(글월).
    반환 v * 2.
}

[시작하기]는 -> 정수 {
    "%lld\n"을 (정수로_바꾸기("21") 혹은 -1)을 쓰다.
    "%lld\n"을 (정수로_바꾸기("가나") 혹은 -1)을 쓰다.
    "%lld\n"을 (두배로("21") 혹은 -1)을 쓰다.
    "%lld\n"을 (두배로("") 혹은 -1)을 쓰다.

    정수 결과 r = 정수로_바꾸기("가나").
    "오류 코드 {r의 오류}\n"을 쓰다.
    반환 0.
}
```

```출력
21
-1
42
-1
오류 코드 2
```

읽는 법은 이렇다.

- `-> 정수 결과` 는 정수 아니면 오류를 돌려준다는 뜻이다.
- `반환 오류(2).` 로 실패를, `반환 값.` 으로 성공을 돌려준다.
- `시도 f(...)` 는 실패하면 그 오류를 그대로 물려주며 지금 함수를 끝낸다. 성공하면 값이다.
- `f(...) 혹은 기본값` 은 실패했을 때 쓸 값을 준다.
- `r의 오류` 와 `r의 값` 으로 직접 볼 수도 있다.

예외를 던지고 받는 장치는 없다. 실패도 그냥 값이다.

## 14장. 마무리 — 낱말 세기

배운 것을 모아 짧은 프로그램을 만든다. 글 한 덩이에서 낱말이 몇 번 나오는지 세어 많이 나온
차례로 보여 준다.

```글
포함 "표준/문자열.gl"
포함 "표준/사전.gl"

묶음 셈은 문자열 낱말, 정수 횟수.

[셈[] 표를 정수 개수를 큰순정렬]는 {
    반복 (정수 i는 1부터 개수 전까지) {
        셈 지금 = 표[i].
        정수 j = i - 1.
        (j >= 0 그리고 표[j]의 횟수 < 지금의 횟수)동안 {
            표[j + 1] = 표[j].
            j를 감소하다.
        }
        표[j + 1] = 지금.
    }
}

[시작하기]는 -> 정수 {
    문자열 글월 = "글은 글이다 글은 재미있다 글이다 글은".

    사전 참조 셈표 = 사전_만들기().
    문자열목록 참조 낱말들 = 문자열_나누기(글월, " " 로).

    반복 (정수 i는 0부터 문자열목록_길이(낱말들) 전까지) {
        문자열 w = 문자열목록_값(낱말들, i).
        사전_넣기(셈표, w, 사전_값_기본(셈표, w, 0) + 1).
    }

    셈[32] 표.
    정수 개수 = 0.
    반복 (정수 자리는 0부터 사전_용량(셈표) 전까지) {
        문자열 키 = 사전_자리키(셈표, 자리).
        키 == 없음이면 { 계속. }
        표[개수]의 낱말 = 키.
        표[개수]의 횟수 = 사전_자리값(셈표, 자리).
        개수를 증가하다.
    }

    큰순정렬(표[0:개수], 개수).

    반복 (정수 k는 0부터 개수 전까지) {
        "{표[k]의 낱말}: {표[k]의 횟수}번\n"을 쓰다.
    }

    문자열목록_해제(낱말들).
    사전_해제(셈표).
    반환 0.
}
```

```출력
글은: 3번
글이다: 2번
재미있다: 1번
```

여기에 이 문서의 거의 모든 것이 들어 있다. 묶음, 배열과 조각, 반복, 조건, 함수, 표준 라이브러리,
그리고 조사로 구별한 호출이다.

## 남겨 둘 자산

- **개념**: 조사 역할 바인딩과 역순 호출 등가(`10000을 20으로 할인계산` = `20으로 10000을 할인계산`), 동사형 호출, 보간, `.` 종결. 모두 릴리즈 바이너리에서 정상 동작 확인.
- **PE 백엔드의 하부**: PE 헤더·섹션·임포트 테이블 기록, x86-64 인코더(movsx/movzx 포함). 릴리즈 재현과 벤치마크로 검증됨. `pe_gen.gl` 5,477줄 중 인코더와 파일 기록 부분만 가져온다.
- **성능 기준선**: fib(40) 492 ms, 버블정렬 30k 1,752 ms, 소수 체 1M 4.6 ms. 2세대 백엔드가 이보다 느리면 회귀다.
- **코퍼스**: `corpus/v1/`의 예제 23, 테스트 17, 프로젝트 6. 단 `자연어_계산.글`과 `테스트_에러.글`은 1세대에서도 컴파일되지 않았고, 나머지도 2세대 문법에 맞게 고쳐야 한다.
- **재현 케이스 20건**: 감사에서 만든 오답·크래시 재현 프로그램. 2세대 부정·회귀 테스트의 씨앗.

- 렉서 전체 (`lexer.gl`)

- `build.py`의 테스트 의미론, `dist_build.ps1`
- `std.gl` 매크로 방식
- C 트랜스파일러·MASM 생성기·ELF 생성기 (`ir_codegen.gl`, `asm_gen.gl`, `elf_gen.gl`, `codegen.gl`, `main_c.gl`)

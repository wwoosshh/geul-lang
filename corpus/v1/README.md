# 1세대 코퍼스 (참고용)

1세대 v0.8.0 저장소의 `examples/`, `tests/`, `projects/`를 그대로 복사한 것이다. **2세대 문법이 아니다.**
D-05가 확정되면 각 파일을 2세대 문법으로 고쳐 `spec-tests/`로 옮기고, 이 디렉터리는 삭제한다.

1세대 릴리즈 바이너리 기준 상태 (2026-09-03 감사):

- `tests/` 17개: 전부 컴파일·실행 통과. 자기검증(실패 시 0이 아닌 종료코드)은 `r02_full`, `role_call_order_test`, `sign_1~5`의 7개뿐.
- `examples/` 23개: 20개 통과. `자연어_계산.글`은 `1을 반환하다` 때문에 컴파일 불가(1세대 결함), `테스트_에러.글`은 의도된 오류 예제, `피보나치.글`은 fib(0..45) 재귀라 수십 초.
- `projects/` 6개: 전부 컴파일됨. 대화형이라 실행 검증은 안 함.

생성 규칙 (대형):
- 함수 N개: `[정수 x를 함수i]는 -> 정수 { 반환 x + i. }` × N. 1세대는 N=2,100에서 "IR 함수 풀 오버플로" 출력 후 크래시.
- 큰 소스: 100자 주석 줄 반복. 1세대는 3.18 MB 정상, 4.76 MB 크래시.
- 한 함수에 `x = x + 1.` × N. 1세대는 N≈256 초과부터 뒤 문장 무음 폐기, 70,000에서 "미해결 패치" 경고 후 실행 크래시.
